 ### Rules
 - **Jumps commit to their direction (owner, 2026-11-12):** like a real jump, the direction cannot be changed in the air (air control 0; the same when walking off a ledge). The direction is chosen at takeoff: the movement keys held at that moment. The second jump can choose a new direction and then commits again. Provisional details (architect): a jump from standing with a direction held leaves at 60% of walking speed at least; the second jump with a direction held leaves at walking speed at least, and with no direction held it keeps the current drift. ## Design (architect, provisional)
### Which directions are searched (probe directions)
The wall is no longer looked for along the view. `FindMantleLedge` takes a probe direction (2D unit vector) and checks
`dot(ProbeDir, -WallNormal2D) >= MantleApproachMinDot` (the sweep must meet the wall roughly head-on) instead of the view.
A new pure function picks the ordered list of directions to try:
```
/** Directions to probe for a ledge, in priority order (2D unit vectors).
    - Intent given (non-zero IntentDir): only that direction (the player chose where to go).
    - No intent: 8 directions 45 degrees apart, starting with ViewForward, then +-45, +-90, +-135, 180
      (positive = counterclockwise first), so the nearest to the view wins. */
void GetProbeDirections(const FVector2D& ViewForward, const FVector2D& IntentDir, TArray<FVector2D>& Out);
```
The first direction that finds a valid ledge wins.
- **Jump pressed on the ground:** intent = the held movement input's world direction (`GetMoveInputWorldDirection(LastMoveInput)`).
  So: standing still with the back to a wall + jump = climb it; holding S (backwards) into a wall + jump = climb it; holding
  W away from a wall behind + jump = a normal forward jump (never a climb behind the player).
- **In the air:** intent = the horizontal velocity direction when its speed is at least `MantleAirSearchMinSpeed`
  (jumps commit to their direction, so the velocity is the intent); slower (a vertical jump, or after hitting a wall, which
  stops the velocity into it) = no intent, all 8 directions. The existing "not moving away" check (`Approach >= -50`) stays,
  against the found wall.
- Cost: the 8-direction search runs only when there is no intent; keep the cheap checks first (the wall sweep) and stop at the
  first hit. No per-tick allocations (use a `TArray` with inline allocator or a fixed array).

### The view turns to the wall
When the climb starts, if the wall faces away from the view by more than `MantleTurnMinAngle` degrees (angle between the
view's yaw forward and -WallNormal2D), the view's yaw turns to face the wall during the climb, so the player ends up on
top looking across it and the hands grip a ledge that is on screen:
- Total turn = the signed shortest yaw delta from the view yaw to the wall-facing yaw (-WallNormal2D), computed at start.
  (No turn when the angle is at most `MantleTurnMinAngle`.)
- Pure: `float TurnFraction(float Alpha, float RiseShare)` = smoothstep from 0 at Alpha 0 to 1 at Alpha = RiseShare, 1 after.
- Each mantle tick, add `(TurnFraction(Alpha) - TurnFraction(PrevAlpha)) * TotalTurn` to the control rotation's yaw
  (deltas, so the mouse still works during the climb and both add up). Only yaw; pitch untouched. Cancel stops turning.
- `CanMantleNow`, inputs, cancel paths, camera dip, held item and HUD hands stay as they are.

### Data (`Content/Data/Player.json` "Stats", constants in `Core/GBStatNames.h`)
- Rename `MantleFacingMinDot` -> `MantleApproachMinDot` (value 0.5; comment: the probe direction must meet the wall at most
  60 degrees off its normal). Remove the old name everywhere.
- New `MantleAirSearchMinSpeed` = 150 (cm/s: in the air, slower than this searches all around).
- New `MantleTurnMinAngle` = 60 (degrees: a wall further off the view than this turns the view to it during the climb).

### Tests (pure, `Tests/GBPlayerTests.cpp`; new test `Glyphbound.Player.MantleProbe`)
- With intent: exactly one direction, equal to the normalized intent (also when the intent is not normalized).
- Without intent: 8 directions, all unit length, the first equals ViewForward, the last is -ViewForward, all 8 distinct and
  45 degrees apart as a set (each one's nearest neighbour is 45 degrees away), the second and third are +45 and -45.
- A different ViewForward rotates the whole list (not fixed world axes).
- `TurnFraction`: 0 at 0, 1 at RiseShare and at 1, strictly between at RiseShare / 2, non-decreasing over 50 samples, and
  for two different RiseShares the value at 0.3 differs.
Each assertion must be able to fail for a wrong implementation.

### Pure logic (new files `Player/GBMantle.h` / `.cpp`, namespace `GBMantle`, no UObject, tested)
```
struct FMantleParams { float MaxReach, MinHeight, AirMinHeight, BaseDuration, DurationPerMeter, RiseShare; };
/** One jump's rise: v^2 / (2 g), g = |GravityZ| * GravityScale (guard g <= 0 -> 0). */
float JumpRise(float JumpZVelocity, float Gravity);
/** From the ground, on a jump press: MinHeight <= LedgeHeight <= JumpRise + MaxReach. */
bool CanMantleFromGround(float LedgeHeight, float JumpRiseCm, const FMantleParams&);
/** In the air: AirMinHeight <= LedgeHeight <= MaxReach. */
bool CanMantleFromAir(float LedgeHeight, const FMantleParams&);
float Duration(float RiseCm, const FMantleParams&);   // >= 0.05 s
/** Actor location along the mantle at Alpha in [0,1]: first (0..RiseShare) straight up from Start to (Start.XY, End.Z)
    with an ease-out, then (RiseShare..1) horizontally to End with a smoothstep. Alpha clamped. Exactly Start at 0, End at 1. */
FVector EvaluatePath(const FVector& Start, const FVector& End, float Alpha, float RiseShare);
/** View pose weights at Alpha (all exactly 0 at Alpha 0 and at Alpha 1):
    ItemLower01: 0 -> 1 over the first 20%, 1 until 75%, 1 -> 0 by 100% (smoothstep each ramp).
    Grip01 (pixel hands on the ledge): 0 -> 1 over 0..15%, 1 until 70%, 1 -> 0 by 90%, 0 after.
    CameraDip01: a smooth bump, 0 at 0, peak 1 at RiseShare (going over the edge), 0 at 1 (e.g. sin-based or two smoothsteps). */
struct FMantlePose { float ItemLower01, Grip01, CameraDip01; };
FMantlePose EvaluatePose(float Alpha, float RiseShare);
```

### Ledge detection (in `AGBPlayerCharacter`, e.g. `bool FindMantleLedge(FMantleLedge& Out) const`)
Using the capsule's world radius R and half height HH, Feet = location.Z - HH, Forward = yaw-only control forward:
1. **Wall:** sweep the player capsule (shrunk by 2 cm in radius) forward from the actor location by MantleProbeDistance
   on `ECC_Pawn` with the capsule's collision response params, ignoring self. Need a blocking hit, not start-penetrating,
   whose actor is not an `APawn` (never climb enemies), and whose `ImpactNormal` is near-horizontal (`|Normal.Z| < 0.3`).
   WallNormal2D = normalized XY of ImpactNormal. Require dot(Forward, -WallNormal2D) >= MantleFacingMinDot.
2. **Top:** sphere sweep (radius 8 cm) straight down at XY = ImpactPoint.XY - WallNormal2D * (MantleTopInset + 8),
   from Z = Feet + (max allowed height for this case) + 20 down to Z = Feet + (min height for this case) - 5. Need a
   blocking non-pawn hit, not start-penetrating, with `ImpactNormal.Z >= GetCharacterMovement()->GetWalkableFloorZ()`.
   LedgeTopZ = hit ImpactPoint.Z; LedgeHeight = LedgeTopZ - Feet. It must pass `CanMantleFromGround` / `CanMantleFromAir`.
3. **Room:** End = (ImpactPoint.XY - WallNormal2D * (R + MantleTopInset), LedgeTopZ + HH + 2). The capsule must fit at End
   and at Mid = (Start.XY, End.Z) (head room above the player): two `OverlapBlockingTestByChannel` with the capsule shape
   (same channel and response params), ignoring self. Either blocked -> no mantle.
4. Output: Start (actor location), End, the ledge edge point (ImpactPoint.XY, LedgeTopZ) for the HUD, the rise (End.Z - Start.Z).

### When it triggers
- **Jump pressed on the ground** (`IsMovingOnGround()`), in `InputJump` before `Jump()`: if a ledge is found with the
  ground limits (max = `JumpRise(JumpZVelocity, |GravityZ|*GravityScale)` + MantleMaxReach), start the mantle and do NOT jump.
  Otherwise the normal jump. (A ledge too high for one jump is a normal jump; the air rule below may still catch it,
  e.g. with the double jump.)
- **In the air** (`MOVE_Falling`, not dashing): every Tick, if a ledge is found with the air limits and the horizontal
  velocity is not moving away from the wall (dot(Velocity2D, -WallNormal2D) >= -50 cm/s), start the mantle. This is the
  "jumps and ends up at the edge" case, rising or falling.
- Never while: dead, control disabled, QTE active, dashing, movement frozen, already mantling.
- Make the jump press reachable by the smoke run: move the body of `InputJump` into a new public `void PressJump()` and
  have `InputJump` call it (same gates as today, plus "not mantling").

### During the mantle
- Start: `ReleaseHeldInputs()`, end any held primary/secondary as that already does; `StopMovementImmediately()`;
  movement mode `MOVE_Flying` keeping `JumpCurrentCount` (same trick as the dash). Store Start, End, ledge point, Duration, Elapsed.
- Tick: Elapsed += DeltaSeconds; `SetActorLocation(GBMantle::EvaluatePath(...))` (no sweep: the path was validated);
  velocity kept at zero. At Alpha >= 1: place at End, `SetMovementMode(MOVE_Walking)`, velocity zero, end.
- Blocked during the mantle: movement input (`ApplyMoveInput` / the QTE held-move path), jump, dash, primary, secondary,
  spell slots, reload, enchant, quick use, block, interact. Look (mouse) stays free.
- `CancelMantle()` (to Falling, everything visual back to rest) from: `HandleDeath`, `FreezeMovement`, `RespawnAt`,
  `LoadFromSnapshot`, `SetControlEnabled(false)`, `EndPlay`.
- Public read-only API for the HUD and the smoke run: `bool IsMantling() const`, `float GetMantleAlpha() const`,
  `FVector GetMantleLedgePoint() const`, `GBMantle::FMantlePose GetMantlePose() const` (zero pose when not mantling).

472-- **Jumps commit to their direction (owner, 2026-11-12):** like a real jump, the direction cannot be changed in the air (air control 0; the same when walking off a ledge). The direction is chosen at takeoff: the movement keys held at that moment. The second jump can choose a new direction and then commits again. Provisional details (architect): a jump from standing with a direction held leaves at 60% of walking speed at least; the second jump with a direction held leaves at walking speed at least, and with no direction held it keeps the current drift. The dash still works in the air and is not affected.
473:- **Ledge climb (owner, 2026-11-13; details provisional, architect):** the player climbs onto a structure in two cases. (1) **In the air**, rising or falling, when a wall is right next to the player in the jump's direction (or anywhere around, if the jump is nearly vertical or was stopped by the wall), and its top is between 15 cm and 1.6 m above the feet (the hands' reach): the climb starts on its own. (2) **Jump pressed on the ground** right against a wall in the held movement direction (or anywhere around when no direction is held: back to the wall works; holding a direction away from a wall behind is a normal jump), whose top is between 0.5 m and one jump's rise plus the 1.6 m reach above the feet: the climb starts instead of the jump; a higher wall is a normal jump (and the double jump can still reach a climb in the air). The wall must be met roughly head-on (within 60° of its face). The view no longer has to face it (owner, v0.45): if the wall is more than 60° off the view, the view turns to face it during the rise, so the player ends on top looking across it; the mouse still works during the turn. There must be room for the player on top and above the head, and floor under the landing point. The climb rises straight up, then moves forward onto the top, in 0.22 s plus 0.18 s per metre of rise; it cannot be steered and blocks attacks, spells, dash and jump while it lasts (looking stays free). Enemies are never climbed. The first-person animation: the held item (staff, sword, gun) drops out of view, both pixel hands come up from the bottom of the screen with their sleeves and grip the ledge where it is on screen, the camera pulls down a little and dips 10° (with a slight roll) as it goes over the edge, then the hands let go and the held item comes back. Numbers in `Player.json` (`Mantle*`). Side effect handled in the test arena: the reach makes things higher reachable, so the last course step now needs the double jump even with a climb, the outer walls went from 11 m to 14 m, and the arena warns if the future-only platform (6 m) could be climbed in the past.

	FVector EvaluatePath(const FVector& Start, const FVector& End, float Alpha, float RiseShare)
	{
		const float A = FMath::Clamp(Alpha, 0.f, 1.f);
		if (A <= 0.f)
		{
			return Start;
		}
		if (A >= 1.f)
		{
			return End;
		}
		const float Share = FMath::Clamp(RiseShare, 0.f, 1.f);
		const FVector Top(Start.X, Start.Y, End.Z);
		if (Share <= KINDA_SMALL_NUMBER)
		{
			return FMath::Lerp(Start, End, Smooth01(0.f, 1.f, A));
		}
		if (Share >= 1.f - KINDA_SMALL_NUMBER)
		{
			const float E = 1.f - (1.f - A) * (1.f - A);
			return FMath::Lerp(Start, Top, E);
		}
		if (A <= Share)
		{
			const float T = A / Share;
			const float E = 1.f - (1.f - T) * (1.f - T);
			return FMath::Lerp(Start, Top, E);
		}
		return FMath::Lerp(Top, End, Smooth01(Share, 1.f, A));
	}

	FMantlePose EvaluatePose(float Alpha, float RiseShare)
	{
		const float A = FMath::Clamp(Alpha, 0.f, 1.f);
		FMantlePose Pose;
		Pose.ItemLower01 = Smooth01(0.f, 0.2f, A) * (1.f - Smooth01(0.75f, 1.f, A));
		Pose.Grip01 = Smooth01(0.f, 0.15f, A) * (1.f - Smooth01(0.7f, 0.9f, A));
		const float Share = FMath::Clamp(RiseShare, 0.f, 1.f);
		if (Share <= KINDA_SMALL_NUMBER || Share >= 1.f - KINDA_SMALL_NUMBER)
		{
			Pose.CameraDip01 = FMath::Sin(UE_PI * A);
		}
		else if (A <= Share)
		{
			Pose.CameraDip01 = Smooth01(0.f, Share, A);
		}
		else
		{
			Pose.CameraDip01 = 1.f - Smooth01(Share, 1.f, A);
		}
		return Pose;
	}

	{
		Out.Reset();
		if (!IntentDir.IsNearlyZero())
		{
			Out.Add(IntentDir.GetSafeNormal());
			return;
		}
		FVector2D Forward = ViewForward.GetSafeNormal();
		if (Forward.IsNearlyZero())
		{
			Forward = FVector2D(1.f, 0.f);
		}
		// 0, +45, -45, +90, -90, +135, -135, 180 degrees (positive = counterclockwise).
		static constexpr float OffsetsDeg[MaxProbeDirections] = { 0.f, 45.f, -45.f, 90.f, -90.f, 135.f, -135.f, 180.f };
		for (float OffsetDeg : OffsetsDeg)
		{
			const float Radians = FMath::DegreesToRadians(OffsetDeg);
			const float C = FMath::Cos(Radians);
			const float S = FMath::Sin(Radians);
			Out.Add(FVector2D(Forward.X * C - Forward.Y * S, Forward.X * S + Forward.Y * C).GetSafeNormal());
		}
	}

	float TurnFraction(float Alpha, float RiseShare)
	{
		const float A = FMath::Clamp(Alpha, 0.f, 1.f);
		const float Share = FMath::Clamp(RiseShare, 0.f, 1.f);
		if (A <= 0.f)
		{
			return 0.f;
		}
		if (Share <= KINDA_SMALL_NUMBER)
		{
			return 1.f;
		}
		if (A >= Share)
		{
			return 1.f;
		}
		const float T = A / Share;
		return T * T * (3.f - 2.f * T);
	}
}

472-- **Jumps commit to their direction (owner, 2026-11-12):** like a real jump, the direction cannot be changed in the air (air control 0; the same when walking off a ledge). The direction is chosen at takeoff: the movement keys held at that moment. The second jump can choose a new direction and then commits again. Provisional details (architect): a jump from standing with a direction held leaves at 60% of walking speed at least; the second jump with a direction held leaves at walking speed at least, and with no direction held it keeps the current drift. The dash still works in the air and is not affected.
473:- **Ledge climb (owner, 2026-11-13; details provisional, architect):** the player climbs onto a structure in two cases. (1) **In the air**, rising or falling, when a wall is right next to the player in the jump's direction (or anywhere around, if the jump is nearly vertical or was stopped by the wall), and its top is between 15 cm and 1.6 m above the feet (the hands' reach): the climb starts on its own. (2) **Jump pressed on the ground** right against a wall in the held movement direction (or anywhere around when no direction is held: back to the wall works; holding a direction away from a wall behind is a normal jump), whose top is between 0.5 m and one jump's rise plus the 1.6 m reach above the feet: the climb starts instead of the jump; a higher wall is a normal jump (and the double jump can still reach a climb in the air). The wall must be met roughly head-on (within 60° of its face). The view no longer has to face it (owner, v0.45): if the wall is more than 60° off the view, the view turns to face it during the rise, so the player ends on top looking across it; the mouse still works during the turn. There must be room for the player on top and above the head, and floor under the landing point. The climb rises straight up, then moves forward onto the top, in 0.22 s plus 0.18 s per metre of rise; it cannot be steered and blocks attacks, spells, dash and jump while it lasts (looking stays free). Enemies are never climbed. The first-person animation: the held item (staff, sword, gun) drops out of view, both pixel hands come up from the bottom of the screen with their sleeves and grip the ledge where it is on screen, the camera pulls down a little and dips 10° (with a slight roll) as it goes over the edge, then the hands let go and the held item comes back. 431: bool AGBPlayerCharacter::FindMantleLedge(FGBMantleLedge& Out, bool bFromGround, const FVector2D& ProbeDir) const
432: {
433: 	UWorld* World = GetWorld();
434: 	UCharacterMovementComponent* MoveComp = GetCharacterMovement();
435: 	const UCapsuleComponent* Capsule = GetCapsuleComponent();
436: 	if (!World || !MoveComp || !Capsule)
437: 	{
438: 		return false;
439: 	}
440: 
441: 	const FVector2D Probe2D = ProbeDir.GetSafeNormal();
442: 	if (Probe2D.IsNearlyZero())
443: 	{
444: 		return false;
445: 	}
446: 
447: 	const float Radius = Capsule->GetScaledCapsuleRadius();
448: 	const float HalfHeight = Capsule->GetScaledCapsuleHalfHeight();
449: 	const FVector ActorLocation = GetActorLocation();
450: 	const float Feet = ActorLocation.Z - HalfHeight;
451: 
452: 	const GBMantle::FMantleParams Params = GetMantleParams();
453: 	const float ProbeDistance = ReadStat(GBStat::MantleProbeDistance, 40.f);
454: 	const float ApproachMinDot = ReadStat(GBStat::MantleApproachMinDot, 0.5f);
455: 	const float TopInset = ReadStat(GBStat::MantleTopInset, 10.f);
456: 
457: 	float JumpRiseCm = 0.f;
458: 	if (bFromGround)
459: 	{
460: 		const float Gravity = FMath::Abs(World->GetGravityZ()) * MoveComp->GravityScale;
461: 		JumpRiseCm = GBMantle::JumpRise(MoveComp->JumpZVelocity, Gravity);
462: 	}
463: 	const float MinHeight = bFromGround ? Params.MinHeight : Params.AirMinHeight;
464: 	const float MaxHeight = bFromGround ? JumpRiseCm + Params.MaxReach : Params.MaxReach;
465: 	if (MaxHeight < MinHeight)
466: 	{
467: 		return false;
468: 	}
469: 
470: 	// The sweep answers as the capsule would: with its own collision responses, ignoring this pawn.
471: 	FCollisionQueryParams QueryParams(SCENE_QUERY_STAT(GBMantleWall), false, this);
472: 	FCollisionResponseParams ResponseParams(Capsule->GetCollisionResponseToChannels());
473: 
474: 	// ---- Wall: the shrunk capsule swept forward. Lifted a little: from the actor location the capsule
475: 	// bottom touches the floor it stands on, which would block (or start-penetrate) the sweep itself.
476: 	// The lift only moves the hit up the same wall face; the edge XY used below does not change.
477: 	constexpr float WallSweepLiftCm = 5.f;
478: 	const FVector WallBase = ActorLocation + FVector(0.f, 0.f, WallSweepLiftCm);
479: 	const float ShrunkRadius = FMath::Max(1.f, Radius - 2.f);
480: 	const FCollisionShape WallShape = FCollisionShape::MakeCapsule(ShrunkRadius, HalfHeight);
481: 	FHitResult WallHit;
482: 	if (!World->SweepSingleByChannel(WallHit, WallBase, WallBase + FVector(Probe2D.X, Probe2D.Y, 0.f) * ProbeDistance,
483: 		FQuat::Identity, ECC_Pawn, WallShape, QueryParams, ResponseParams)
484: 		|| !WallHit.bBlockingHit || WallHit.bStartPenetrating)
485: 	{
486: 		return false;
487: 	}
488: 	AActor* WallActor = WallHit.GetActor();
489: 	if (!WallActor || WallActor->IsA<APawn>())
490: 	{
491: 		return false;
492: 	}
493: 	if (FMath::Abs(WallHit.ImpactNormal.Z) >= 0.3f)
494: 	{
495: 		return false;
496: 	}
497: 	FVector2D WallNormal2D(WallHit.ImpactNormal.X, WallHit.ImpactNormal.Y);
498: 	if (!WallNormal2D.Normalize())
499: 	{
500: 		return false;
501: 	}
502: 	if (FVector2D::DotProduct(Probe2D, -WallNormal2D) < ApproachMinDot)
503: 	{
504: 		return false;
505: 	}
506: 
507: 	// ---- Top: a small sphere swept down behind the wall face. ----
508: 	const FVector2D Edge2D(WallHit.ImpactPoint.X, WallHit.ImpactPoint.Y);
509: 	const FVector2D TopXY = Edge2D - WallNormal2D * (TopInset + 8.f);
510: 	const FVector TopStart(TopXY.X, TopXY.Y, Feet + MaxHeight + 20.f);
511: 	const FVector TopEnd(TopXY.X, TopXY.Y, Feet + MinHeight - 5.f);
512: 	FHitResult TopHit;
513: 	if (!World->SweepSingleByChannel(TopHit, TopStart, TopEnd, FQuat::Identity, ECC_Pawn,
514: 		FCollisionShape::MakeSphere(8.f), QueryParams, ResponseParams)
515: 		|| !TopHit.bBlockingHit || TopHit.bStartPenetrating)
516: 	{
517: 		return false;
518: 	}
519: 	AActor* TopActor = TopHit.GetActor();
520: 	if (!TopActor || TopActor->IsA<APawn>())
521: 	{
522: 		return false;
523: 	}
524: 	if (TopHit.ImpactNormal.Z < MoveComp->GetWalkableFloorZ())
525: 	{
526: 		return false;
527: 	}
528: 	const float LedgeTopZ = TopHit.ImpactPoint.Z;
529: 	const float LedgeHeight = LedgeTopZ - Feet;
530: 	const bool bHeightOk = bFromGround
531: 		? GBMantle::CanMantleFromGround(LedgeHeight, JumpRiseCm, Params)
532: 		: GBMantle::CanMantleFromAir(LedgeHeight, Params);
533: 	if (!bHeightOk)
534: 	{
535: 		return false;
536: 	}
537: 
538: 	// ---- Room: the capsule must fit at the end, and the whole path (straight up, then forward) must be clear,
539: 	// so a thin ceiling or beam between the checked poses is never passed through. The path sweeps use the shrunk
540: 	// capsule, lifted like the wall sweep, so the wall it slides along and the floor it leaves do not count.
541: 	const FVector2D EndXY = Edge2D - WallNormal2D * (Radius + TopInset);
542: 	const FVector End(EndXY.X, EndXY.Y, LedgeTopZ + HalfHeight + 2.f);
543: 	const FVector Mid(ActorLocation.X, ActorLocation.Y, End.Z);
544: 	const FCollisionShape FitShape = FCollisionShape::MakeCapsule(Radius, HalfHeight);
545: 	if (World->OverlapBlockingTestByChannel(End, FQuat::Identity, ECC_Pawn, FitShape, QueryParams, ResponseParams))
546: 	{
547: 		return false;
548: 	}
549: 	FHitResult PathHit;
550: 	if (Mid.Z > WallBase.Z && World->SweepSingleByChannel(PathHit, WallBase, Mid, FQuat::Identity, ECC_Pawn, WallShape, QueryParams, ResponseParams))
551: 	{
552: 		return false;
553: 	}
554: 	if (World->SweepSingleByChannel(PathHit, Mid, End, FQuat::Identity, ECC_Pawn, WallShape, QueryParams, ResponseParams))
555: 	{
556: 		return false;
557: 	}
558: 	// ---- Support: walkable floor under the end (a thin beam can give a top hit with nothing under the capsule centre).
559: 	FHitResult FloorHit;
560: 	const FVector FloorEnd = End - FVector(0.f, 0.f, HalfHeight + 2.f + MoveComp->MaxStepHeight);
561: 	if (!World->LineTraceSingleByChannel(FloorHit, End, FloorEnd, ECC_Pawn, QueryParams, ResponseParams)
562: 		|| FloorHit.bStartPenetrating || FloorHit.ImpactNormal.Z < MoveComp->GetWalkableFloorZ()
563: 		|| (FloorHit.GetActor() && FloorHit.GetActor()->IsA<APawn>()))
564: 	{
565: 		return false;
566: 	}
567: 
568: 	Out.Start = ActorLocation;
569: 	Out.End = End;
570: 	Out.LedgePoint = FVector(Edge2D.X, Edge2D.Y, LedgeTopZ);
571: 	Out.RiseCm = End.Z - ActorLocation.Z;
572: 	Out.WallNormal2D = WallNormal2D;
573: 	return true;
574: }

576: bool AGBPlayerCharacter::TryStartMantle(bool bFromGround)
577: {
578: 	if (!CanMantleNow())
579: 	{
580: 		return false;
581: 	}
582: 	UCharacterMovementComponent* MoveComp = GetCharacterMovement();
583: 	if (MoveComp)
584: 	{
585: 		if (bFromGround)
586: 		{
587: 			if (!MoveComp->IsMovingOnGround())
588: 			{
589: 				return false;
590: 			}
591: 		}
592: 		else if (MoveComp->MovementMode != MOVE_Falling)
593: 		{
594: 			return false;
595: 		}
596: 	}
597: 	FGBMantleLedge Ledge;
598: 	bool bFound = false;
599: 	// Intent: on the ground the held movement input's world direction, in the air the horizontal velocity when
600: 	// it is fast enough (jumps commit to their direction). With an intent only that way is tried, so holding away
601: 	// from a wall behind never climbs it; without one every direction is tried, starting with the view.
602: 	FVector2D Intent2D = FVector2D::ZeroVector;
603: 	if (bFromGround)
604: 	{
605: 		const FVector WorldDir = GetMoveInputWorldDirection(LastMoveInput);
606: 		Intent2D = FVector2D(WorldDir.X, WorldDir.Y);
607: 	}
608: 	else if (MoveComp)
609: 	{
610: 		const FVector Velocity = MoveComp->Velocity;
611: 		const FVector2D Velocity2D(Velocity.X, Velocity.Y);
612: 		if (Velocity2D.Size() >= ReadStat(GBStat::MantleAirSearchMinSpeed, 150.f))
613: 		{
614: 			Intent2D = Velocity2D;
615: 		}
616: 	}
617: 	const float ViewYaw = Controller ? Controller->GetControlRotation().Yaw : GetActorRotation().Yaw;
618: 	const FVector ViewForward = FRotator(0.f, ViewYaw, 0.f).Vector();
619: 	TArray<FVector2D, TInlineAllocator<GBMantle::MaxProbeDirections>> Probes;
620: 	GBMantle::GetProbeDirections(FVector2D(ViewForward.X, ViewForward.Y), Intent2D, Probes);
621: 	for (const FVector2D& Probe : Probes)
622: 	{
623: 		if (!FindMantleLedge(Ledge, bFromGround, Probe))
624: 		{
625: 			continue;
626: 		}
627: 		if (!bFromGround && MoveComp)
628: 		{
629: 			// Still falling away from the found wall: not a grab, keep looking around.
630: 			const FVector Velocity = MoveComp->Velocity;
631: 			const float Approach = -(Velocity.X * Ledge.WallNormal2D.X + Velocity.Y * Ledge.WallNormal2D.Y);
632: 			if (Approach < -50.f)
633: 			{
634: 				continue;
635: 			}
636: 		}
637: 		bFound = true;
638: 		break;
639: 	}
640: 	if (!bFound)
641: 	{
642: 		return false;
643: 	}
644: 	StartMantle(Ledge);
645: 	return true;
646: }

649: {

		float Smooth01(float Edge0, float Edge1, float X)
		{
			const float T = FMath::Clamp((X - Edge0) / (Edge1 - Edge0), 0.f, 1.f);
			return T * T * (3.f - 2.f * T);
		}
	}

	float JumpRise(float JumpZVelocity, float Gravity)
	{
		if (Gravity <= 0.f)
		{
			return 0.f;
		}
		return JumpZVelocity * JumpZVelocity / (2.f * Gravity);
	}

	bool CanMantleFromGround(float LedgeHeight, float JumpRiseCm, const FMantleParams& Params)
	{
		return LedgeHeight >= Params.MinHeight && LedgeHeight <= JumpRiseCm + Params.MaxReach;
	}

	bool CanMantleFromAir(float LedgeHeight, const FMantleParams& Params)
	{
		return LedgeHeight >= Params.AirMinHeight && LedgeHeight <= Params.MaxReach;
	}

	float Duration(float RiseCm, const FMantleParams& Params)
	{
		return FMath::Max(0.05f, Params.BaseDuration + Params.DurationPerMeter * RiseCm / 100.f);
	}

	FVector EvaluatePath(const FVector& Start, const FVector& End, float Alpha, float RiseShare)
	{
		const float A = FMath::Clamp(Alpha, 0.f, 1.f);
		if (A <= 0.f)
		{
			return Start;
		}
		if (A >= 1.f)
		{
			return End;
		}
		const float Share = FMath::Clamp(RiseShare, 0.f, 1.f);
		const FVector Top(Start.X, Start.Y, End.Z);
		if (Share <= KINDA_SMALL_NUMBER)
		{
			return FMath::Lerp(Start, End, Smooth01(0.f, 1.f, A));
		}
		if (Share >= 1.f - KINDA_SMALL_NUMBER)
		{
			const float E = 1.f - (1.f - A) * (1.f - A);
			return FMath::Lerp(Start, Top, E);
		}
		if (A <= Share)
		{
			const float T = A / Share;
			const float E = 1.f - (1.f - T) * (1.f - T);
			return FMath::Lerp(Start, Top, E);
		}
		return FMath::Lerp(Top, End, Smooth01(Share, 1.f, A));
	}

	FMantlePose EvaluatePose(float Alpha, float RiseShare)

	float TurnFraction(float Alpha, float RiseShare)
	{
		const float A = FMath::Clamp(Alpha, 0.f, 1.f);
		const float Share = FMath::Clamp(RiseShare, 0.f, 1.f);
		if (A <= 0.f)
		{
			return 0.f;
		}
		if (Share <= KINDA_SMALL_NUMBER)
		{
			return 1.f;
		}
		if (A >= Share)
		{
			return 1.f;
		}
		const float T = A / Share;
		return T * T * (3.f - 2.f * T);
	}

I found an input-ordering defect: UE 5.9 dispatches jump’s `Started` event before movement’s `Triggered` event, so pressing a direction and jump together can make the mantle search use the previous frame’s direction. The smoke hook bypasses that path. I also found gaps where the new tests would accept incorrect behavior.

- **[P2] Jump reads stale movement intent — [GBPlayerCharacter.cpp:605](/C:/GameJam/Glyphbound/Source/Glyphbound/Player/GBPlayerCharacter.cpp:605)** — Standing with your back to a wall, press forward and jump in the same frame. UE 5.9 dispatches jump’s `Started` callback before movement’s `Triggered` callback, so `LastMoveInput` is still zero. The all-around search finds the wall behind and starts a backward climb. Changing or releasing directions alongside jump similarly uses stale intent. **Fix:** sample the current evaluated movement action before choosing probes, or defer the jump decision until movement input has been updated. `SetMoveInputForTest` bypasses this ordering defect.

- **[P3] Held-away smoke never verifies a normal jump — [GBDevCommands.cpp:3456](/C:/GameJam/Glyphbound/Source/Glyphbound/Core/GBDevCommands.cpp:3456)** — The assertion samples `IsMantling()` immediately after `PressJump()`, before movement processes the jump. An implementation that simply returns without jumping passes; a later airborne backward grab also escapes this check. The subsequent reset can run in the same ticker invocation when the schedule falls behind. **Fix:** add a simulated-time-gated follow-up before resetting position, checking falling mode, increased height, velocity away from the wall, and no mantle.

- **[P3] Probe test accepts incorrect search priority — [GBPlayerTests.cpp:247](/C:/GameJam/Glyphbound/Source/Glyphbound/Tests/GBPlayerTests.cpp:247)** — Swapping the ±90° probes with the ±135° probes passes every assertion: the directions remain distinct, evenly spaced, and rotate correctly with the view. With valid walls at +90° and +135°, that implementation chooses the farther-off-view wall first. **Fix:** assert every ordered direction against `0, +45, -45, +90, -90, +135, -135, 180`.

- **[P3] Turn test accepts linear interpolation — [GBPlayerTests.cpp:279](/C:/GameJam/Glyphbound/Source/Glyphbound/Tests/GBPlayerTests.cpp:279)** — `Clamp(Alpha / RiseShare, 0, 1)` passes all current turn assertions despite violating the required smoothstep, producing abrupt angular-speed changes at the turn’s endpoints. **Fix:** assert interior smoothstep values, such as `0.15625` and `0.84375` at one-quarter and three-quarters of `RiseShare`.
