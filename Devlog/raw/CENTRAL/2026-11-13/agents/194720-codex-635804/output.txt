## What the owner asked (translated from Spanish)
"When the character jumps and ends up at the edge of a structure, it should play the climb animation and climb up
that structure. Also, when the character is right against a block/structure and presses jump, if the jump is high
enough, it should play the climb animation and climb that structure/block instead of jumping."

The game is first person (camera only, no body mesh). The player's hands are 2D pixel-art sprites drawn by the HUD
(`UI/GBHUD.cpp`, `AGBHUD::DrawHands`), guns are 3D models attached to `HeldItemAnchor` under the camera. So the

## Design (architect, provisional; numbers are data)

### New stats in `Glyphbound/Content/Data/Player.json` "Stats" (add constants in `Core/GBStatNames.h`, `GBStat::`)
| Stat | Value | Meaning |
|---|---|---|
| MantleMaxReach | 160 | cm: the highest a ledge top can be above the feet for the hands to reach it |
| MantleMinHeight | 50 | cm: from the ground, a ledge lower than this above the feet is not climbed (it is jumped / stepped) |
| MantleAirMinHeight | 15 | cm: in the air, a ledge top less than this above the feet is not climbed (the player just lands) |
| MantleProbeDistance | 40 | cm: how far in front of the capsule a wall is looked for |
| MantleFacingMinDot | 0.5 | the view's yaw forward must face the wall: dot(forward2D, -wallNormal2D) >= this |
| MantleTopInset | 10 | cm: the capsule ends this far past the ledge edge (its edge, not its centre: centre = edge + radius + inset) |
| MantleBaseDuration | 0.22 | s |
| MantleDurationPerMeter | 0.18 | s per metre of rise (duration = base + per metre * rise / 100) |
| MantleRiseShare | 0.6 | share of the duration spent rising straight up; the rest moves forward onto the top |

Read them with `ReadStat` like every other movement stat (they then work with modifiers and missing-stat warnings).

### Pure logic (new files `Player/GBMantle.h` / `.cpp`, namespace `GBMantle`, no UObject, tested)
```
struct FMantleParams { float MaxReach, MinHeight, AirMinHeight, BaseDuration, DurationPerMeter, RiseShare; };
/** One jump's rise: v^2 / (2 g), g = |GravityZ| * GravityScale (guard g <= 0 -> 0). */
float JumpRise(float JumpZVelocity, float Gravity);
/** From the ground, on a jump press: MinHeight <= LedgeHeight <= JumpRise + MaxReach. */
bool CanMantleFromGround(float LedgeHeight, float JumpRiseCm, const FMantleParams&);
/** In the air: AirMinHeight <= LedgeHeight <= MaxReach. */
bool CanMantleFromAir(float LedgeHeight, const FMantleParams&);
float Duration(float RiseCm, const FMantleParams&);   // >= 0.05 s
/** Actor location along the mantle at Alpha in [0,1]: first (0..RiseShare) straight up from Start to (Start.XY, End.Z)
    with an ease-out, then (RiseShare..1) horizontally to End with a smoothstep. Alpha clamped. Exactly Start at 0, End at 1. */
FVector EvaluatePath(const FVector& Start, const FVector& End, float Alpha, float RiseShare);
/** View pose weights at Alpha (all exactly 0 at Alpha 0 and at Alpha 1):
    ItemLower01: 0 -> 1 over the first 20%, 1 until 75%, 1 -> 0 by 100% (smoothstep each ramp).
    Grip01 (pixel hands on the ledge): 0 -> 1 over 0..15%, 1 until 70%, 1 -> 0 by 90%, 0 after.
    CameraDip01: a smooth bump, 0 at 0, peak 1 at RiseShare (going over the edge), 0 at 1 (e.g. sin-based or two smoothsteps). */
struct FMantlePose { float ItemLower01, Grip01, CameraDip01; };
FMantlePose EvaluatePose(float Alpha, float RiseShare);
```

### Ledge detection (in `AGBPlayerCharacter`, e.g. `bool FindMantleLedge(FMantleLedge& Out) const`)
Using the capsule's world radius R and half height HH, Feet = location.Z - HH, Forward = yaw-only control forward:
1. **Wall:** sweep the player capsule (shrunk by 2 cm in radius) forward from the actor location by MantleProbeDistance
   on `ECC_Pawn` with the capsule's collision response params, ignoring self. Need a blocking hit, not start-penetrating,
   whose actor is not an `APawn` (never climb enemies), and whose `ImpactNormal` is near-horizontal (`|Normal.Z| < 0.3`).
   WallNormal2D = normalized XY of ImpactNormal. Require dot(Forward, -WallNormal2D) >= MantleFacingMinDot.
2. **Top:** sphere sweep (radius 8 cm) straight down at XY = ImpactPoint.XY - WallNormal2D * (MantleTopInset + 8),
   from Z = Feet + (max allowed height for this case) + 20 down to Z = Feet + (min height for this case) - 5. Need a
   blocking non-pawn hit, not start-penetrating, with `ImpactNormal.Z >= GetCharacterMovement()->GetWalkableFloorZ()`.
   LedgeTopZ = hit ImpactPoint.Z; LedgeHeight = LedgeTopZ - Feet. It must pass `CanMantleFromGround` / `CanMantleFromAir`.
3. **Room:** End = (ImpactPoint.XY - WallNormal2D * (R + MantleTopInset), LedgeTopZ + HH + 2). The capsule must fit at End
   and at Mid = (Start.XY, End.Z) (head room above the player): two `OverlapBlockingTestByChannel` with the capsule shape
   (same channel and response params), ignoring self. Either blocked -> no mantle.
4. Output: Start (actor location), End, the ledge edge point (ImpactPoint.XY, LedgeTopZ) for the HUD, the rise (End.Z - Start.Z).

### When it triggers
- **Jump pressed on the ground** (`IsMovingOnGround()`), in `InputJump` before `Jump()`: if a ledge is found with the
  ground limits (max = `JumpRise(JumpZVelocity, |GravityZ|*GravityScale)` + MantleMaxReach), start the mantle and do NOT jump.
  Otherwise the normal jump. (A ledge too high for one jump is a normal jump; the air rule below may still catch it,
  e.g. with the double jump.)
- **In the air** (`MOVE_Falling`, not dashing): every Tick, if a ledge is found with the air limits and the horizontal
  velocity is not moving away from the wall (dot(Velocity2D, -WallNormal2D) >= -50 cm/s), start the mantle. This is the
  "jumps and ends up at the edge" case, rising or falling.
- Never while: dead, control disabled, QTE active, dashing, movement frozen, already mantling.
- Make the jump press reachable by the smoke run: move the body of `InputJump` into a new public `void PressJump()` and
  have `InputJump` call it (same gates as today, plus "not mantling").

### During the mantle
- Start: `ReleaseHeldInputs()`, end any held primary/secondary as that already does; `StopMovementImmediately()`;
  movement mode `MOVE_Flying` keeping `JumpCurrentCount` (same trick as the dash). Store Start, End, ledge point, Duration, Elapsed.
- Tick: Elapsed += DeltaSeconds; `SetActorLocation(GBMantle::EvaluatePath(...))` (no sweep: the path was validated);
  velocity kept at zero. At Alpha >= 1: place at End, `SetMovementMode(MOVE_Walking)`, velocity zero, end.
- Blocked during the mantle: movement input (`ApplyMoveInput` / the QTE held-move path), jump, dash, primary, secondary,
  spell slots, reload, enchant, quick use, block, interact. Look (mouse) stays free.
- `CancelMantle()` (to Falling, everything visual back to rest) from: `HandleDeath`, `FreezeMovement`, `RespawnAt`,
  `LoadFromSnapshot`, `SetControlEnabled(false)`, `EndPlay`.
- Public read-only API for the HUD and the smoke run: `bool IsMantling() const`, `float GetMantleAlpha() const`,
  `FVector GetMantleLedgePoint() const`, `GBMantle::FMantlePose GetMantlePose() const` (zero pose when not mantling).

### The first-person animation
1. **Camera (view only, aim untouched):** pitch down by `CameraDip01 * 10` degrees and roll by `CameraDip01 * 3` degrees,
   plus a relative location drop of `Grip01 * 6` cm (the pull on the arms). Compose it with the
   existing view shake: `TickViewShake` must not overwrite it, and neither may leave a residue. Do it with one place that
   sets `Camera->SetRelativeRotation(Shake + Mantle)` and `Camera->SetRelativeLocation(Base eye + mantle offset)`, and
   returns exactly to zero / the base eye height when both are done (the base eye height comes from `BaseEyeHeight`).
   Keep these three numbers as named constants in the file's anonymous namespace ("feel and visual constants").
2. **Held item:** `HeldItemAnchor` relative location = `HeldItemOffset + FVector(-10, 0, -35) * ItemLower01` (the gun
   drops out of view), exactly `HeldItemOffset` at rest.
3. **Pixel hands (`AGBHUD::DrawHands`):** while mantling,
   - the normal pose (staff / gun hands / sword / bare hand / left hand / cast hand / shield) slides down off screen:
     add `ItemLower01 * Canvas->ClipY * 0.7` to the baseline `H` they are all placed from, so all of them go down together;
   - the two climbing hands: `hand_left` and `hand_right` sprites (existing) gripping the ledge. Project the ledge point
     to the screen (`Canvas->Project` or the player controller's `ProjectWorldLocationToScreen`); grip line Y = projected Y
     clamped to [0.12, 0.85] * ClipY (if the projection fails, 0.45 * ClipY). Hand centres at X = 0.38 W and 0.62 W. The
     knuckles (top of the sprite) sit on the grip line when Grip01 = 1; with Grip01 < 1 the hands are lowered by
     `(1 - Grip01) * (ClipY - GripY + sprite height)` (they come up from below the screen and go back down).
   - **Sleeves:** below each climbing hand, draw the sprite's cuff rows (the bottom 8 rows of the 20-row sprite: the

     (nearest filtering, same pixel size P), so the arms reach up from the bottom edge. Look at how `DrawSprite` draws and
     add a small helper for the sub-rect tile.
   - Skip the cast hand and the raised shield while mantling.

  Design\GDD.md:57:## 0.1 Technical direction
  Design\GDD.md:58:- **Engine:** Unreal Engine 5.9.0, pinned until submission. **Single player only.**
  Design\GDD.md:59:- **Architect autonomy:** nobody on the team is a programmer. **Every technical and engineering 
decision is the architect's**, taken without asking the owner: code architecture, C++ vs. Blueprints, plugins, tools, 
data formats, optimization. Decide, build, and log the decision and its reason in the dev log. When a design detail is 
missing, pick a reasonable provisional value, mark it provisional here, and keep going; ask the owner only when the 
game's vision would change.
  Design\GDD.md:60:- **Time first:** iteration speed matters more than elegance. Unused plugins off, Live Coding for 
`.cpp` changes, only the touched tests on each change, the full suite (under 30 s) once before the daily package. 
Rules in `CLAUDE.md` ("Tiempo de iteración").
  Design\GDD.md:61:- **Code (decided by the architect, 2026-11-12):** C++ only, one module, no Blueprint graphs; 
structure in `Design/ARCHITECTURE.md`. **Unreal's Gameplay Ability System is not used**: a small stat-and-modifier 
system, one damage function and one status-effect component cover the same needs with far less setup.
  Design\GDD.md:62:- **Tuning data (decided by the architect):** every gameplay number lives in text files, 
`Glyphbound/Content/Data/*.json` (spells, weapons, enemies, items, skills, player, QTE...). They ship as loose files: 
the owner can change numbers in a packaged build with a text editor, and `gb.ReloadData` in the console reloads them 
while playing. This replaces the data tables suggested earlier (git only carries text in this team, and AI agents edit 
text reliably).
  Design\GDD.md:63:- **Test level (decided by the architect):** the day-1 test arena is built in code on the engine's 
empty map, so no binary map asset is needed yet. Real levels come later from the level designers.
  Design\GDD.md:64:- **Placeholders first:** pixel art and 3D models are made by other team members on machines on the 
local network. **The architect never waits for art:** it uses quickly generated placeholders and swaps them later.
  Design\GDD.md:65:- **Placeholder numbers:** the architect puts provisional values (damage, mana, cooldowns, QTE 
length and time limit…) in data tables; the owner tunes them later.
  Design\GDD.md:66:- **PIE is human-only:** Play In Editor is always run by a person. AI agents do not run PIE; they 
compile, package and run tests, then ask a human to play-test. (Also in `CLAUDE.md`.)
  Design\GDD.md:67:- **Era travel:** a fade with an effect when crossing a portal; the transition hides loading the 
other era's version of the map.
  Design\GDD.md:68:- **Saving:** checkpoints only. No save to disk between sessions.
  Design\GDD.md:69:- **Size:** the jam page says "keep it under 1 GB" for desktop zips, but **bigger builds are 
allowed** if uploaded with butler (installed on CENTRAL) or Blendo Itch Uploader. The Official Rules PDF sets no size 
limit. So 1 GB is a target, not a hard limit.

  Design\GDD.md:73:## 1. One-line pitch
  Design\GDD.md:74:A fast first-person **shooter/RPG hybrid**: the player, a medieval mage, jumps through fixed

  Design\GDD.md:469:
  Design\GDD.md:470:### Rules
  Design\GDD.md:471:- **Jumps commit to their direction (owner, 2026-11-12):** like a real jump, the direction cannot 
be changed in the air (air control 0; the same when walking off a ledge). The direction is chosen at takeoff: the 
movement keys held at that moment. The second jump can choose a new direction and then commits again. Provisional 
details (architect): a jump from standing with a direction held leaves at 60% of walking speed at least; the second 
jump with a direction held leaves at walking speed at least, and with no direction held it keeps the current drift. 
The dash still works in the air and is not affected.
> Design\GDD.md:472:- **Ledge climb (owner, 2026-11-13; details provisional, architect):** the player climbs onto a 
structure in two cases. (1) **In the air**, rising or falling, when the view faces a wall (within 60° of straight at 
it), the wall is right in front, and its top is between 15 cm and 1.6 m above the feet (the hands' reach): the climb 
starts on its own. (2) **Jump pressed on the ground** right against a wall the view faces, whose top is between 0.5 m 
and one jump's rise plus the 1.6 m reach above the feet: the climb starts instead of the jump; a higher wall is a 
normal jump (and the double jump can still reach a climb in the air). There must be room for the player on top and 
above the head. The climb rises straight up, then moves forward onto the top, in 0.22 s plus 0.18 s per metre of rise; 
it cannot be steered and blocks attacks, spells, dash and jump while it lasts (looking stays free). Enemies are never 
climbed. The first-person animation: the held item (staff, sword, gun) drops out of view, both pixel hands come up 
from the bottom of the screen with their sleeves and grip the ledge where it is on screen, the camera pulls down a 
little and dips 10° (with a slight roll) as it goes over the edge, then the hands let go and the held item comes back. 
Numbers in `Player.json` (`Mantle*`). Side effect handled in the test arena: the reach makes things higher reachable, 
so the last course step now needs the double jump even with a climb, the outer walls went from 11 m to 14 m, and the 
arena warns if the future-only platform (6 m) could be climbed in the past.
  Design\GDD.md:473:- **Double jump on day 1:** the player starts knowing the air passive "Double jump" so it can be 
tested now. In the real game it is learned in the air zone (§6); remove it from `Player.json` `StartingSpells` then.
  Design\GDD.md:474:- **Dash:** available from the start (the air passive only improves it). It goes in the movement 
direction (forward when standing still), works in the air, gives no invulnerability, and does not refill jumps.
  Design\GDD.md:475:- **Owning weapons:** decided by the owner for staffs (section 8): picked-up weapons go to the 
inventory and are equipped by hand. Provisional part: guns and the sword follow the same rule; each owned gun keeps 
its own ammo while stored.
  Design\GDD.md:476:- **Reload:** the bullets left in the old magazine are lost (classic tactical style). A gun 
reloads by itself when its magazine runs dry. Ammo pickups give one spare magazine, up to the gun's maximum.
  Design\GDD.md:477:  - **The shotgun loads shell by shell (owner, 2026-11-12).** One shell goes in at a time; nothing 
is lost by reloading early, and the reload can stop part-way. Provisional (architect): its reserve is counted in 
shells (4 magazines x 6 = 24, the same total as before); each shell takes `ReloadTime / MagazineSize` (0.33 s), so a 
full reload from empty still takes the 2 s the balance tables use and Rapid Reload speeds it the same way; pressing 
fire during the reload stops it and shoots as soon as a shell is in (the shell on its way in is not lost: it stays in 
the reserve); an ammo pickup gives one magazine's worth of shells (6); an empty shotgun still starts reloading by 
itself. **As built (v0.34):** pressing fire stops the reload at that moment, even inside the time between shots, and 
the shot follows when the fire rate allows; on an empty gun the press (a tap is enough) is kept, the first shell 
lands, the reload stops and the gun fires; a weapon switch, a death or an ammo refill drops that kept shot. The gun's 
data says it reloads per round (`ReloadPerRound` 1 in `Weapons.json`); the HUD shows the reserve as "x24 shells".
  Design\GDD.md:478:  - **The shotgun's forend pumps after every shot (owner, 2026-11-12).** Provisional (architect): 
it is only the look; the time between shots stays `FireInterval` (0.8 s) and the pump plays inside it. **As built 
(v0.34), provisional art values:** it starts back at 22% of the interval, is fully back at 45% and home at 72%; the 
gun dips 0.5 cm and rolls 1.5° with it and the 2D left hand rides it. From the first-person camera the pump itself is 
under the gun and hardly seen.
  Design\GDD.md:479:  - **The shotgun's energy bar (owner, 2026-11-13):** it stays on top of the receiver, where the 
approved model has it, although the camera sees it almost edge-on; the architect offered to move it to the sight's 
rear panel and the owner declined.
  Design\GDD.md:480:- **Sustained spells (flamethrower), changed by the owner (2026-11-12):** after the QTE the 
flamethrower runs **while its spell key is held**, until the key is released or the mana runs out (also on weapon 
switch or death). No time limit. Provisional (architect): it pays a smaller cost at the start (10 mana, always spent, 
like every QTE spell) and then drains 15 mana per second; if the key was already released when the QTE ends, it still 
burns for a short minimum (0.75 s) so the cast is never wasted; the cooldown starts at the cast. All values in 
`Spells.json` (`ManaCost`, `ManaPerSecond`, `MinDuration`).
  Design\GDD.md:481:- **Strong hit interrupts the flamethrower (owner, 2026-11-12):** a single hit that takes **30% or 
more of the player's maximum health** stops it at once, and the camera shakes. The in-game description says "a strong 
hit", never the number. Provisional (architect): measured against maximum health (not current health), on the damage 
actually taken after the ice shield and armor; the threshold is a spell parameter (`InterruptHitFraction`, so any 
sustained spell can use it); the shake is short (about 0.35 s, a few degrees, values in `Game.json`), only moves the 
view, never the aim; the mana already spent is not refunded and the cooldown is unchanged.
  Design\GDD.md:482:- **Spread while moving (owner, 2026-11-12; numbers by the architect, provisional):** each gun 
adds `MoveSpread` (hip fire) or `AimMoveSpread` (aiming) degrees to its spread, scaled by the player's horizontal 
speed over the current walk speed (0 standing still, full bonus at full walk speed or faster; aiming already lowers 
the walk speed, so a slow aimed walk counts as full). Pistol 1.2 -> 3.7 hip, 0.25 -> 1.25 aimed; shotgun 6 -> 9, 4.5 
-> 6.5; rifle 1.8 -> 4.8, 0.35 -> 1.55 (`Weapons.json`, modifiable by perks as `Weapon.<Id>.MoveSpread`). Jumping 
counts by its horizontal speed only.

+bool AGBPlayerCharacter::FindMantleLedge(FGBMantleLedge& Out, bool bFromGround) const
+{
+	UWorld* World = GetWorld();
+	UCharacterMovementComponent* MoveComp = GetCharacterMovement();
+	const UCapsuleComponent* Capsule = GetCapsuleComponent();
+	if (!World || !MoveComp || !Capsule)
+	{
+		return false;
+	}
+
+	const float Radius = Capsule->GetScaledCapsuleRadius();
+	const float HalfHeight = Capsule->GetScaledCapsuleHalfHeight();
+	const FVector ActorLocation = GetActorLocation();
+	const float Feet = ActorLocation.Z - HalfHeight;
+	const float Yaw = Controller ? Controller->GetControlRotation().Yaw : GetActorRotation().Yaw;
+	const FVector Forward = FRotator(0.f, Yaw, 0.f).Vector();
+	const FVector2D Forward2D = FVector2D(Forward.X, Forward.Y).GetSafeNormal();
+
+	const GBMantle::FMantleParams Params = GetMantleParams();
+	const float ProbeDistance = ReadStat(GBStat::MantleProbeDistance, 40.f);
+	const float FacingMinDot = ReadStat(GBStat::MantleFacingMinDot, 0.5f);
+	const float TopInset = ReadStat(GBStat::MantleTopInset, 10.f);
+
+	float JumpRiseCm = 0.f;
+	if (bFromGround)
+	{
+		const float Gravity = FMath::Abs(World->GetGravityZ()) * MoveComp->GravityScale;
+		JumpRiseCm = GBMantle::JumpRise(MoveComp->JumpZVelocity, Gravity);
+	}
+	const float MinHeight = bFromGround ? Params.MinHeight : Params.AirMinHeight;
+	const float MaxHeight = bFromGround ? JumpRiseCm + Params.MaxReach : Params.MaxReach;
+	if (MaxHeight < MinHeight)
+	{
+		return false;
+	}
+
+	// The sweep answers as the capsule would: with its own collision responses, ignoring this pawn.
+	FCollisionQueryParams QueryParams(SCENE_QUERY_STAT(GBMantleWall), false, this);
+	FCollisionResponseParams ResponseParams(Capsule->GetCollisionResponseToChannels());
+
+	// ---- Wall: the shrunk capsule swept forward. Lifted a little: from the actor location the capsule
+	// bottom touches the floor it stands on, which would block (or start-penetrate) the sweep itself.
+	// The lift only moves the hit up the same wall face; the edge XY used below does not change.
+	constexpr float WallSweepLiftCm = 5.f;
+	const FVector WallBase = ActorLocation + FVector(0.f, 0.f, WallSweepLiftCm);
+	const float ShrunkRadius = FMath::Max(1.f, Radius - 2.f);
+	const FCollisionShape WallShape = FCollisionShape::MakeCapsule(ShrunkRadius, HalfHeight);
+	FHitResult WallHit;
+	if (!World->SweepSingleByChannel(WallHit, WallBase, WallBase + Forward * ProbeDistance,
+		FQuat::Identity, ECC_Pawn, WallShape, QueryParams, ResponseParams)
+		|| !WallHit.bBlockingHit || WallHit.bStartPenetrating)
+	{
+		return false;
+	}
+	AActor* WallActor = WallHit.GetActor();
+	if (!WallActor || WallActor->IsA<APawn>())
+	{
+		return false;
+	}
+	if (FMath::Abs(WallHit.ImpactNormal.Z) >= 0.3f)
+	{
+		return false;
+	}
+	FVector2D WallNormal2D(WallHit.ImpactNormal.X, WallHit.ImpactNormal.Y);
+	if (!WallNormal2D.Normalize())
+	{
+		return false;
+	}
+	if (FVector2D::DotProduct(Forward2D, -WallNormal2D) < FacingMinDot)
+	{
+		return false;
+	}
+
+	// ---- Top: a small sphere swept down behind the wall face. ----
+	const FVector2D Edge2D(WallHit.ImpactPoint.X, WallHit.ImpactPoint.Y);
+	const FVector2D TopXY = Edge2D - WallNormal2D * (TopInset + 8.f);
+	const FVector TopStart(TopXY.X, TopXY.Y, Feet + MaxHeight + 20.f);
+	const FVector TopEnd(TopXY.X, TopXY.Y, Feet + MinHeight - 5.f);
+	FHitResult TopHit;
+	if (!World->SweepSingleByChannel(TopHit, TopStart, TopEnd, FQuat::Identity, ECC_Pawn,
+		FCollisionShape::MakeSphere(8.f), QueryParams, ResponseParams)
+		|| !TopHit.bBlockingHit || TopHit.bStartPenetrating)
+	{
+		return false;
+	}
+	AActor* TopActor = TopHit.GetActor();
+	if (!TopActor || TopActor->IsA<APawn>())
+	{
+		return false;
+	}
+	if (TopHit.ImpactNormal.Z < MoveComp->GetWalkableFloorZ())
+	{
+		return false;
+	}
+	const float LedgeTopZ = TopHit.ImpactPoint.Z;
+	const float LedgeHeight = LedgeTopZ - Feet;
+	const bool bHeightOk = bFromGround
+		? GBMantle::CanMantleFromGround(LedgeHeight, JumpRiseCm, Params)
+		: GBMantle::CanMantleFromAir(LedgeHeight, Params);
+	if (!bHeightOk)
+	{
+		return false;
+	}
+
+	// ---- Room: the capsule must fit at the end and above the start (head room). ----
+	const FVector2D EndXY = Edge2D - WallNormal2D * (Radius + TopInset);
+	const FVector End(EndXY.X, EndXY.Y, LedgeTopZ + HalfHeight + 2.f);
+	const FVector Mid(ActorLocation.X, ActorLocation.Y, End.Z);
+	const FCollisionShape FitShape = FCollisionShape::MakeCapsule(Radius, HalfHeight);
+	if (World->OverlapBlockingTestByChannel(End, FQuat::Identity, ECC_Pawn, FitShape, QueryParams, ResponseParams))
+	{
+		return false;
+	}
+	if (World->OverlapBlockingTestByChannel(Mid, FQuat::Identity, ECC_Pawn, FitShape, QueryParams, ResponseParams))
+	{
+		return false;
+	}
+
+	Out.Start = ActorLocation;
+	Out.End = End;
+	Out.LedgePoint = FVector(Edge2D.X, Edge2D.Y, LedgeTopZ);
+	Out.RiseCm = End.Z - ActorLocation.Z;
+	Out.WallNormal2D = WallNormal2D;
+	return true;
+}

+{

+	{

+	if (UCharacterMovementComponent* MoveComp = GetCharacterMovement())
+	{
+		if (bFromGround)
+		{
+			if (!MoveComp->IsMovingOnGround())
+			{
+				return false;
+			}
+		}
+		else if (MoveComp->MovementMode != MOVE_Falling)
+		{

// Ledge climb (mantle) math: pure logic with no UObject, so the automation tests can cover it (GDD: climb).
#pragma once

#include "CoreMinimal.h"

namespace GBMantle
{
	/** Tunables from Player.json (all cm / seconds; RiseShare is a 0..1 fraction). */
	struct FMantleParams
	{
		float MaxReach = 160.f;
		float MinHeight = 50.f;
		float AirMinHeight = 15.f;
		float BaseDuration = 0.22f;
		float DurationPerMeter = 0.18f;
		float RiseShare = 0.6f;
	};

	/** View pose weights at one point of the climb, all 0..1. */
	struct FMantlePose
	{
		float ItemLower01 = 0.f;
		float Grip01 = 0.f;
		float CameraDip01 = 0.f;
	};

	/** One jump's rise: v^2 / (2 g). Guards a non-positive gravity (returns 0). Units follow the inputs (cm). */
	float JumpRise(float JumpZVelocity, float Gravity);
	/** From the ground, on a jump press: MinHeight <= LedgeHeight <= JumpRise + MaxReach. */
	bool CanMantleFromGround(float LedgeHeight, float JumpRiseCm, const FMantleParams& Params);
	/** In the air: AirMinHeight <= LedgeHeight <= MaxReach. */
	bool CanMantleFromAir(float LedgeHeight, const FMantleParams& Params);
	/** Climb duration from the rise: base + per-metre * rise / 100, at least 0.05 s. */
	float Duration(float RiseCm, const FMantleParams& Params);
	/**
	 * Actor location along the mantle at Alpha in [0,1] (clamped). The first RiseShare of Alpha goes straight
	 * up from Start to (Start.XY, End.Z) with an ease-out; the rest goes horizontally to End with a smoothstep.
	 * Exactly Start at 0 and End at 1.
	 */
	FVector EvaluatePath(const FVector& Start, const FVector& End, float Alpha, float RiseShare);
	/** View pose weights at Alpha (clamped). All exactly 0 at Alpha 0 and at Alpha 1. */
	FMantlePose EvaluatePose(float Alpha, float RiseShare);
}
#include "Player/GBMantle.h"

namespace GBMantle
{
	namespace
	{
		float Smooth01(float Edge0, float Edge1, float X)
		{
			const float T = FMath::Clamp((X - Edge0) / (Edge1 - Edge0), 0.f, 1.f);
			return T * T * (3.f - 2.f * T);
		}
	}

	float JumpRise(float JumpZVelocity, float Gravity)
	{
		if (Gravity <= 0.f)
		{
			return 0.f;
		}
		return JumpZVelocity * JumpZVelocity / (2.f * Gravity);
	}

	bool CanMantleFromGround(float LedgeHeight, float JumpRiseCm, const FMantleParams& Params)
	{
		return LedgeHeight >= Params.MinHeight && LedgeHeight <= JumpRiseCm + Params.MaxReach;
	}

	bool CanMantleFromAir(float LedgeHeight, const FMantleParams& Params)
	{
		return LedgeHeight >= Params.AirMinHeight && LedgeHeight <= Params.MaxReach;
	}

	float Duration(float RiseCm, const FMantleParams& Params)
	{
		return FMath::Max(0.05f, Params.BaseDuration + Params.DurationPerMeter * RiseCm / 100.f);
	}

	FVector EvaluatePath(const FVector& Start, const FVector& End, float Alpha, float RiseShare)
	{
		const float A = FMath::Clamp(Alpha, 0.f, 1.f);
		if (A <= 0.f)
		{
			return Start;
		}
		if (A >= 1.f)
		{
			return End;
		}
		const float Share = FMath::Clamp(RiseShare, 0.f, 1.f);
		const FVector Top(Start.X, Start.Y, End.Z);
		if (Share <= KINDA_SMALL_NUMBER)
		{
			return FMath::Lerp(Start, End, Smooth01(0.f, 1.f, A));
		}
		if (Share >= 1.f - KINDA_SMALL_NUMBER)
		{
			const float E = 1.f - (1.f - A) * (1.f - A);
			return FMath::Lerp(Start, Top, E);
		}
		if (A <= Share)
		{
			const float T = A / Share;
			const float E = 1.f - (1.f - T) * (1.f - T);
			return FMath::Lerp(Start, Top, E);
		}
		return FMath::Lerp(Top, End, Smooth01(Share, 1.f, A));
	}

	FMantlePose EvaluatePose(float Alpha, float RiseShare)
	{
		const float A = FMath::Clamp(Alpha, 0.f, 1.f);
		FMantlePose Pose;
		Pose.ItemLower01 = Smooth01(0.f, 0.2f, A) * (1.f - Smooth01(0.75f, 1.f, A));
		Pose.Grip01 = Smooth01(0.f, 0.15f, A) * (1.f - Smooth01(0.7f, 0.9f, A));
		const float Share = FMath::Clamp(RiseShare, 0.f, 1.f);
		if (Share <= KINDA_SMALL_NUMBER || Share >= 1.f - KINDA_SMALL_NUMBER)
		{
			Pose.CameraDip01 = FMath::Sin(UE_PI * A);
		}
		else if (A <= Share)
		{
			Pose.CameraDip01 = Smooth01(0.f, Share, A);
		}
		else
		{
			Pose.CameraDip01 = 1.f - Smooth01(Share, 1.f, A);
		}
		return Pose;
	}
}

void AGBPlayerCharacter::BeginPlay()
{
	Super::BeginPlay();

	UGBDataSubsystem* Data = UGBDataSubsystem::Get(this);
	if (!Data)
	{
		UE_LOG(LogGB, Warning, TEXT("GBPlayerCharacter: no data subsystem, the player starts with default stats."));
	}

	if (Data)
	{
		Stats->SetBaseStats(Data->GetPlayer().Stats);
	}
	Attributes->Team = EGBTeam::Player;
	Attributes->InitializeFromStats();

	if (Data)
	{
		// Copy: GiveWeapon reads the data tables, never keep a reference into them across calls.
		const TArray<FName> StartingWeapons = Data->GetPlayer().StartingWeapons;
		for (int32 Index = 0; Index < StartingWeapons.Num(); ++Index)
		{
			if (!Data->FindWeapon(StartingWeapons[Index]))
			{
				UE_LOG(LogGB, Warning, TEXT("GBPlayerCharacter: starting weapon '%s' is not in Weapons.json."), *StartingWeapons[Index].ToString());
				continue;
			}
			// Same rule as pickups: the first of each kind goes to its slot, the others are stored.
			Equipment->GiveWeapon(StartingWeapons[Index], Index == 0);
		}
	}

	Spellbook->InitializeFromData();
	Inventory->InitializeFromData();
	SkillTree->InitializeFromData();

	Stats->OnStatsChanged.AddUObject(this, &AGBPlayerCharacter::ApplyMovementStats);
	Attributes->OnDeath.AddUObject(this, &AGBPlayerCharacter::HandleDeath);
	DamageDealtHandle = UGBCombatLibrary::OnDamageDealt().AddUObject(this, &AGBPlayerCharacter::HandlePrecisionRecovery);
	if (Data)
	{
		DataReloadedHandle = Data->OnDataReloaded.AddUObject(this, &AGBPlayerCharacter::HandleDataReloaded);
	}

	// Passives learned above changed stats before the binding existed.
	ApplyMovementStats();

	if (UGBProgressSubsystem* Progress = UGBProgressSubsystem::Get(this))
	{
		if (!Progress->HasCheckpoint())
		{
			Progress->SaveCheckpoint(this);
		}
	}
}

void AGBPlayerCharacter::EndPlay(const EEndPlayReason::Type EndPlayReason)
{
	CancelMantle();
	UGBCombatLibrary::OnDamageDealt().Remove(DamageDealtHandle);
	DamageDealtHandle.Reset();
	if (UGBDataSubsystem* Data = UGBDataSubsystem::Get(this))
	{
		Data->OnDataReloaded.Remove(DataReloadedHandle);
	}
	DataReloadedHandle.Reset();
	Super::EndPlay(EndPlayReason);
}

void AGBPlayerCharacter::HandleDataReloaded()
{
	if (UGBDataSubsystem* Data = UGBDataSubsystem::Get(this))
	{
		Stats->SetBaseStats(Data->GetPlayer().Stats);
	}
}

void AGBPlayerCharacter::Tick(float DeltaSeconds)
{
	Super::Tick(DeltaSeconds);

	UpdateFocusedInteractable();

	if (IsQTEActive())
	{
		// GDD 7: the movement keys are busy with the QTE, so the last movement input is held.
		if (CanUseGameplayInput() && !bDashing && !LastMoveInput.IsNearlyZero())
		{
			ApplyMoveInput(LastMoveInput);
		}
	}
	else if (GFrameCounter > LastMoveInputFrame + 1)
	{
		// No Move event for a frame: the stick / keys were released (also covers releases during a QTE).
		LastMoveInput = FVector2D::ZeroVector;
	}

	if (bDashing)
	{
		DashTimeLeft -= DeltaSeconds;
		if (DashTimeLeft <= 0.f)
		{
			EndDash();
		}
		else if (UCharacterMovementComponent* MoveComp = GetCharacterMovement())
		{
			MoveComp->Velocity = DashVelocity;
		}
	}

	if (bMantling)
	{
		TickMantle(DeltaSeconds);
	}
	else if (UCharacterMovementComponent* MoveComp = GetCharacterMovement())
	{
		// In the air (rising or falling): grab a ledge in front instead of sailing past it.
		if (CanMantleNow() && MoveComp->MovementMode == MOVE_Falling)
		{
			FGBMantleLedge AirLedge;
			if (FindMantleLedge(AirLedge, /*bFromGround*/ false))
			{
				const FVector Velocity = MoveComp->Velocity;
				const float Approach = -(Velocity.X * AirLedge.WallNormal2D.X + Velocity.Y * AirLedge.WallNormal2D.Y);
				if (Approach >= -50.f)
				{
					StartMantle(AirLedge);
				}
			}
		}
	}

	TickRecoil(DeltaSeconds);
	TickViewShake(DeltaSeconds);
}

float AGBPlayerCharacter::ReadStat(FName Stat, float DefaultValue) const
{
	if (!Stats)
	{
		return DefaultValue;
	}
	if (!Stats->HasBaseStat(Stat) && !GWarnedMissingPlayerStats.Contains(Stat))
	{
		GWarnedMissingPlayerStats.Add(Stat);
		UE_LOG(LogGB, Warning, TEXT("GBPlayerCharacter: stat '%s' is missing from Player.json, using %.2f."), *Stat.ToString(), DefaultValue);
	}
	return Stats->GetStat(Stat, DefaultValue);
}

void AGBPlayerCharacter::ApplyMovementStats()
{
	UCharacterMovementComponent* MoveComp = GetCharacterMovement();
	if (!MoveComp)
	{
		return;
	}

	UpdateWalkSpeed();
	MoveComp->JumpZVelocity = FMath::Max(0.f, ReadStat(GBStat::JumpVelocity, 620.f));
	MoveComp->AirControl = FMath::Max(0.f, ReadStat(GBStat::AirControl, 0.f));
	MoveComp->GravityScale = ReadStat(GBStat::GravityScale, 1.6f);
	// Committed jumps (GDD 18): no air steering, no air braking or lateral friction, so the takeoff keeps its speed.
	MoveComp->BrakingDecelerationFalling = 0.f;
	MoveComp->FallingLateralFriction = 0.f;
	JumpMaxCount = FMath::Max(1, FMath::RoundToInt(ReadStat(GBStat::MaxJumps, 1.f)));

	UCapsuleComponent* Capsule = GetCapsuleComponent();
	const float Radius = FMath::Max(1.f, ReadStat(GBStat::CapsuleRadius, 38.f));
	const float HalfHeight = FMath::Max(Radius, ReadStat(GBStat::CapsuleHalfHeight, 90.f));
	const float OldHalfHeight = Capsule->GetUnscaledCapsuleHalfHeight();
	if (!FMath::IsNearlyEqual(OldHalfHeight, HalfHeight) || !FMath::IsNearlyEqual(Capsule->GetUnscaledCapsuleRadius(), Radius))
	{
		const bool bWasOnGround = MoveComp->IsMovingOnGround();
		Capsule->SetCapsuleSize(Radius, HalfHeight, true);
		if (bWasOnGround && HalfHeight > OldHalfHeight)
		{
			// Keep the feet on the floor instead of sinking into it.
			AddActorWorldOffset(FVector(0.f, 0.f, HalfHeight - OldHalfHeight));
		}
	}

	BaseEyeHeight = ReadStat(GBStat::EyeHeight, 70.f);
	ApplyCameraPose();
}

void AGBPlayerCharacter::UpdateWalkSpeed()
{
	UCharacterMovementComponent* MoveComp = GetCharacterMovement();
	if (!MoveComp)
	{
		return;
	}
	const float Speed = FMath::Max(0.f, ReadStat(GBStat::MoveSpeed, 750.f) * MoveSpeedScale);
	MoveComp->MaxWalkSpeed = Speed;
	MoveComp->MaxAcceleration = FMath::Max(1.f, Speed * ReadStat(GBStat::AccelerationPerSpeed, 10.f));
	MoveComp->BrakingDecelerationWalking = Speed * ReadStat(GBStat::BrakingPerSpeed, 8.f);
	MoveComp->GroundFriction = ReadStat(GBStat::GroundFriction, 8.f);
}

void AGBPlayerCharacter::SetMoveSpeedScale(float Scale)
{
	MoveSpeedScale = FMath::Max(0.f, Scale);
	UpdateWalkSpeed();
}

void AGBPlayerCharacter::ApplyMoveInput(const FVector2D& Input)
{
	if (bMantling)
	{
		return;
	}
	const FRotator YawRotation(0.f, GetControlRotation().Yaw, 0.f);
	const FRotationMatrix YawMatrix(YawRotation);
	AddMovementInput(YawMatrix.GetUnitAxis(EAxis::X), Input.Y);
	AddMovementInput(YawMatrix.GetUnitAxis(EAxis::Y), Input.X);
}

FVector AGBPlayerCharacter::GetMoveInputWorldDirection(const FVector2D& Input) const
{
	if (Input.IsNearlyZero())
	{
		return FVector::ZeroVector;
	}
	const FRotator YawRotation(0.f, GetControlRotation().Yaw, 0.f);
	const FRotationMatrix YawMatrix(YawRotation);
	FVector Direction = YawMatrix.GetUnitAxis(EAxis::X) * Input.Y + YawMatrix.GetUnitAxis(EAxis::Y) * Input.X;
	Direction.Z = 0.f;
	if (!Direction.Normalize())
	{
		return FVector::ZeroVector;
	}
	return Direction;
}

FVector2D AGBPlayerCharacter::ComputeJumpHorizontalVelocity(const FVector2D& CurrentVelocity, const FVector2D& InputDirection, float MaxWalkSpeed, float MinSpeedMult)
{
	if (InputDirection.IsNearlyZero())
	{
		return CurrentVelocity;
	}
	const FVector2D Direction = InputDirection.GetSafeNormal();
	const float CurrentSpeed = CurrentVelocity.Size();
	const float MinSpeed = FMath::Max(0.f, MaxWalkSpeed) * FMath::Max(0.f, MinSpeedMult);
	return Direction * FMath::Max(CurrentSpeed, MinSpeed);
}

void AGBPlayerCharacter::OnJumped_Implementation()
{
	// JumpCurrentCount is 1 for a jump from the ground, 2+ for a jump that starts in the air
	// (double jump, or the first jump after walking off a ledge: CheckJumpInput pre-increments while falling).
	const bool bGroundJump = JumpCurrentCount <= 1;
	const float MinSpeedMult = ReadStat(bGroundJump ? GBStat::JumpTakeoffMinSpeedMult : GBStat::AirJumpMinSpeedMult,
		bGroundJump ? 0.6f : 1.0f);
	if (UCharacterMovementComponent* MoveComp = GetCharacterMovement())
	{
		const FVector2D CurrentVelocity(MoveComp->Velocity.X, MoveComp->Velocity.Y);
		const FVector WorldDir = GetMoveInputWorldDirection(LastMoveInput);
		const FVector2D NewHorizontal = ComputeJumpHorizontalVelocity(CurrentVelocity,
			FVector2D(WorldDir.X, WorldDir.Y), MoveComp->MaxWalkSpeed, MinSpeedMult);
		// The engine already set the vertical velocity; only the horizontal direction commits here.
		MoveComp->Velocity.X = NewHorizontal.X;
		MoveComp->Velocity.Y = NewHorizontal.Y;
	}
}

void AGBPlayerCharacter::AddLookDelta(float YawDegrees, float PitchDegrees)
{
	if (!Controller)
	{
		return;
	}
	FRotator Rotation = Controller->GetControlRotation();
	Rotation.Yaw = FRotator::NormalizeAxis(Rotation.Yaw + YawDegrees);
	const double PitchLimit = ReadStat(GBStat::PitchLimit, 89.f);
	Rotation.Pitch = FMath::Clamp(FRotator::NormalizeAxis(Rotation.Pitch + PitchDegrees), -PitchLimit, PitchLimit);
	Rotation.Roll = 0.f;
	Controller->SetControlRotation(Rotation);
}

void AGBPlayerCharacter::EndDash()
{
	if (!bDashing)
	{
		return;
	}
	bDashing = false;
	DashTimeLeft = 0.f;

	UCharacterMovementComponent* MoveComp = GetCharacterMovement();
	if (MoveComp && MoveComp->MovementMode == MOVE_Flying)
	{
		// Changing movement mode may reset the jump count: keep it, so a dash never refills jumps.
		const int32 SavedJumpCount = JumpCurrentCount;
		MoveComp->SetMovementMode(MOVE_Falling);
		JumpCurrentCount = SavedJumpCount;
		MoveComp->Velocity = DashVelocity.GetSafeNormal() * MoveComp->MaxWalkSpeed * ReadStat(GBStat::DashExitSpeedMult, 1.f);
	}
}

	static bool Tick(float)
	{
		UWorld* World = SmokeWorld.Get();
		if (!World)
		{
			UE_LOG(LogGB, Error, TEXT("SMOKE aborted: the world went away"));
			return false;
		}
		// Read the clock again for every step: a step may wind StartSeconds back (the reload steps stretch the run).
		while (NextStep < Steps.Num() && Steps[NextStep].Time <= static_cast<float>(FPlatformTime::Seconds() - StartSeconds))
		{
			const FStep& Gate = Steps[NextStep];
			if (Gate.MinSimSinceMark > 0.f && World->GetTimeSeconds() - SimMark < Gate.MinSimSinceMark
				&& FPlatformTime::Seconds() - StartSeconds - Gate.Time < SimGateTimeoutSeconds)
			{
				break; // not enough simulated time since the first sample yet: try again next tick
			}
			const FStep& Step = Steps[NextStep++];
			AGBPlayerCharacter* Player = AGBPlayerCharacter::Get(World);
			UE_LOG(LogGB, Display, TEXT("SMOKE step %d/%d (%.1f s): %s"), NextStep, Steps.Num(), Step.Time, Step.Name);
			if (!Player)
			{
				UE_LOG(LogGB, Error, TEXT("SMOKE step skipped: there is no player character"));
				continue;
			}
			Step.Run(World, Player);
		}
		return NextStep < Steps.Num();
	}

	static void Start(const TArray<FString>& Args, UWorld* World)
	{
		if (!World || !World->IsGameWorld())
		{
			UE_LOG(LogGB, Warning, TEXT("gb.Smoke needs a running game world"));
			return;
		}
		BuildSteps();
		if (Args.Num() > 0)
		{
			// Filtered run (gb.Smoke Entity): only the steps whose name starts with the argument, plus the quit step, from 1 s on.
			const FString Prefix = Args[0];
			Steps.RemoveAll([&Prefix](const FStep& Step) { return !FString(Step.Name).StartsWith(Prefix, ESearchCase::IgnoreCase) && FCString::Strcmp(Step.Name, TEXT("quit")) != 0; });
			if (Steps.Num() <= 1)
			{
				UE_LOG(LogGB, Warning, TEXT("gb.Smoke %s: no step starts with that name"), *Prefix);
			}
			float FirstTime = Steps.Num() > 0 ? Steps[0].Time : 0.f;
			for (const FStep& Step : Steps)
			{
				FirstTime = FMath::Min(FirstTime, Step.Time);
			}
			for (FStep& Step : Steps)
			{
				Step.Time -= FirstTime - 1.f;
			}
		}
		NextStep = 0;
		StartSeconds = FPlatformTime::Seconds();
		SmokeWorld = World;
		FTSTicker::GetCoreTicker().RemoveTicker(TickerHandle);
		TickerHandle = FTSTicker::GetCoreTicker().AddTicker(FTickerDelegate::CreateStatic(&Tick));
		UE_LOG(LogGB, Display, TEXT("SMOKE started: %d steps"), Steps.Num());
}

FVector UCanvas::Project(FVector Location, bool bClampToZeroPlane) const 
{
	FPlane V(0,0,0,0);

	if (SceneView != NULL)
	{
		Location.DiagnosticCheckNaN();
		V = SceneView->Project(Location);
	}

	FVector resultVec(V);
	resultVec.X = (ClipX/2.f) + (resultVec.X*(ClipX/2.f));
	resultVec.Y *= -1.f * GProjectionSignY;
	resultVec.Y = (ClipY/2.f) + (resultVec.Y*(ClipY/2.f));

	// if behind the screen, clamp depth to the screen
	if (bClampToZeroPlane && V.W <= 0.0f) 
	{
		resultVec.Z = 0.0f;
	}
	return resultVec;
}

void AGBPlayerCharacter::FellOutOfWorld(const UDamageType& /*DmgType*/)
{
	// Never Super: the engine would destroy the pawn. The checkpoint respawn brings the player back.
	if (IsDead())
	{
		FreezeMovement(); // already dead (or killed by the first call): just keep it from falling forever
		return;
	}
	if (!Attributes)
	{
		return;
	}

	EndDash();
	FreezeMovement();

	// Friendly fire and invulnerability do not matter here: the hit goes straight to the attributes.
	const bool bWasInvulnerable = Attributes->IsInvulnerable();
	Attributes->SetInvulnerable(false);
	FGBDamageInfo Fall;
	Fall.Amount = FallOutOfWorldDamage;
	Fall.Element = EGBElement::Physical;
	Fall.SourceId = FellOutOfWorldSourceId;
	Attributes->ApplyDamage(Fall); // HitDirection is zero, so a raised shield cannot block it
	Attributes->SetInvulnerable(bWasInvulnerable);

	if (!IsDead())
	{
		// Only a data setup with DamageTaken 0 gets here: respawn directly rather than fall forever.
		UE_LOG(LogGB, Warning, TEXT("GBPlayerCharacter: fell out of the world but could not be killed (DamageTaken 0?); respawning at the checkpoint."));
		if (UGBProgressSubsystem* Progress = UGBProgressSubsystem::Get(this))
		{
			if (Progress->RestoreCheckpoint(this))
			{
				return;
			}
		}
		UnfreezeMovement();
	}
}

void UGBEraSubsystem::Tick(float DeltaTime)
{
	Super::Tick(DeltaTime);

	if (!bTravelling)
	{
		return;
	}

	// The fade runs in real time: the spell QTE slows the world, the fade must not slow with it.
	const UWorld* World = GetWorld();
	const float RealDelta = FMath::Clamp(World ? World->DeltaRealTimeSeconds : DeltaTime, 0.f, GBEraSubsystemLocal::MaxFadeStep);
	StageTime += RealDelta;

	if (TravelStage == 0)
	{
		FadeAlpha = FadeOutTime > 0.f ? FMath::Clamp(StageTime / FadeOutTime, 0.f, 1.f) : 1.f;
		// Health and mana are only raised towards the fractions, never lowered. Never for a dead player
		// (death undoes the travel before this point).
		if (!Player->IsDead())
		{
			const UGBDataSubsystem* RestoreData = UGBDataSubsystem::Get(this);
			const float HealthFraction = RestoreData ? RestoreData->GetGameValue(GBGameValue::EraTravelHealthFraction, 1.f) : 1.f;
			const float ManaFraction = RestoreData ? RestoreData->GetGameValue(GBGameValue::EraTravelManaFraction, 1.f) : 1.f;
			const bool bRefillAmmo = RestoreData ? RestoreData->GetGameValue(GBGameValue::EraTravelRefillAmmo, 1.f) > 0.5f : true;
			Player->RestoreAll(HealthFraction, ManaFraction, bRefillAmmo, /*bOnlyRaise*/ true);
			if (UGBProgressSubsystem* Progress = UGBProgressSubsystem::Get(this))
			{
				Progress->SaveCheckpoint(Player);
			}
		}
	}
}

void UGBEraSubsystem::FinishTravel()
{
	FadeAlpha = 0.f;
	bTravelling = false;
	TravelStage = 0;
	StageTime = 0.f;

	if (AGBPlayerCharacter* Player = Cast<AGBPlayerCharacter>(PendingTraveller.Get()))
	{
		Player->SetControlEnabled(true);
	}
	PendingTraveller.Reset();

	OnTravelFinished.Broadcast(CurrentEra);
}
