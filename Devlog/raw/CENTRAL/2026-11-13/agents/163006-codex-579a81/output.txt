# Review: weapon perks per gun (data, smoke steps, balance tool) — Glyphbound (UE 5.9)

You are reviewing, read-only. Run `git diff HEAD -- Glyphbound/Content/Data Glyphbound/Source Tools/Balance` and read
what the diff touches. Ignore Devlog and GDD files except where asked below.

What changed (owner: "perks per gun"):
1. `Skills.json`: the weapon tree's shared perks are gone. Every gun branch (Pistol, Rifle, Shotgun; the hub UI from
   the previous commit shows each branch as its own page) gets its own Quick Trigger (`Weapon.<Gun>.FireInterval`
   x0.92 per rank), Rapid Reload (`Weapon.<Gun>.ReloadTime` x0.9) and Steady Grip (`Weapon.<Gun>.RecoilPitch` and
   `RecoilYaw` x0.8). Signature chains: Pistol Deadeye -> Marksman (still `Weapon.All.HeadshotMult`, on purpose:
   it is the staff's and sword's only weak-point perk) -> Precision Recovery; Rifle Long Shot -> Arcane Conduit (now
   `Weapon.Rifle.EnchantBuildUpMult`); Shotgun Point Blank -> Tight Choke (new: `Weapon.Shotgun.Spread` and
   `AimSpread` x0.9). Old ids `Weapon_FireRate`, `Weapon_ReloadSpeed`, `Weapon_Recoil`, `Weapon_EnchantBuildUp` are
   removed; the 22-node count became 29.
2. `Enemies.json`: each Entity phase 8,000 -> 7,300 health, because the old `Weapon.All.FireInterval` /
   `ReloadTime` perks also sped up the staff and the sword (`AGBHeldItem::GetStat` evaluates the gun's id key, its
   slot key and the All key), and the balance tool showed the Entity fight growing from 191 to 214 s (target 160-200).
3. `GBDevCommands.cpp` (smoke): the perk steps use the pistol's new ids; Marksman now needs Deadeye, so Deadeye is
   unlocked first; the Arcane Conduit check gives and equips the Rifle, checks x1.3 build-up, then re-equips the
   Pistol; the node count check is 29.
4. `Tools/Balance/balance_model.js`: reference builds moved to the pistol ids; the gun specialist swaps the old
   all-gun Recoil / Conduit for Pistol Steady Grip and Shotgun Tight Choke (same 33 points).

## What to look for (ranked)
1. Data bugs: a modifier key the game does not resolve (the data subsystem warns about unknown weapon keys at load;
   check that every new key is a real stat of that gun in `Weapons.json`), a requirement on a missing id, a node
   that cannot be reached, a description that does not match its modifier, ops that stack differently from what the
   description says (how do several ranks of a Multiply 0.9 combine? the smoke expects 3 ranks of Rapid Reload to
   give exactly 0.7 x base).
2. Smoke: the rifle swap in the Arcane Conduit step leaving the player in a state later steps do not expect (which
   gun is in the gun slot, ammo, the enchant still on the rifle, the later rifle block calling GiveWeapon("Rifle")
   again on an owned weapon), the reset checks, point arithmetic (points added vs. spent with the new costs).
3. Anything else in code, tests or tools that still names the removed ids or relies on "All guns" perks (for
   example HUD text, tutorials, save data, balance tables).
4. The balance reasoning: is lowering Entity health the right lever for the cause described, given how the tool
   models the fight? Only flag a concrete error.

Do not suggest style rewrites or new features. For each finding give: file:line, what goes wrong, a concrete scenario,
and a fix. If you find nothing real, say so plainly.

	{
		if (const float* Value = Def->Stats.Find(Stat))
		{
			Base = *Value;
		}
	}

	if (const UGBStatsComponent* Stats = GetOwnerStats())
	{
		TArray<FName, TInlineAllocator<3>> Keys;
		Keys.Add(GBStat::WeaponKey(WeaponId, Stat));

bool AGBHeldItem::GetActiveEnchant(EGBElement& OutElement, FName& OutOnHitEffect) const
{
	const AGBPlayerCharacter* Player = GetPlayerOwner();
	const UGBStatusEffectComponent* Effects = Player ? Player->GetStatusEffects() : nullptr;
	const UGBDataSubsystem* Data = UGBDataSubsystem::Get(this);
	if (!Effects || !Data)
	{
		return false;
	}

	for (const FGBActiveStatusEffect& Active : Effects->GetActiveEffects())
	{
		const FGBStatusEffectDefinition* Def = Data->FindStatusEffect(Active.EffectId);
		if (!Def)
		{
			continue;
		}
		const FString* ElementName = Def->Strings.Find(GBWeaponString::WeaponElement);
		if (!ElementName || ElementName->IsEmpty())
		{
			continue;
		}
		const int64 Value = StaticEnum<EGBElement>()->GetValueByNameString(*ElementName);
		if (Value == INDEX_NONE)
		{
			UE_LOG(LogGB, Warning, TEXT("Status effect '%s': unknown WeaponElement '%s'"), *Active.EffectId.ToString(), **ElementName);
			continue;
		}
		OutElement = static_cast<EGBElement>(Value);
		const FString* Effect = Def->Strings.Find(GBWeaponString::WeaponOnHitEffect);
		OutOnHitEffect = (Effect && !Effect->IsEmpty()) ? FName(**Effect) : NAME_None;
		return true;
	}
	return false;
}

FGBDamageInfo AGBHeldItem::MakeDamageInfo() const
{
	FGBDamageInfo Info;
	Info.Amount = GetStat(GBStat::Damage);
	Info.Element = Element;
	Info.Instigator = GetPlayerOwner();
	Info.Causer = const_cast<AGBHeldItem*>(this);
	Info.SourceId = WeaponId;

	if (const FGBWeaponDefinition* Def = GetDefinition())
	{
		if (const FString* Effect = Def->Strings.Find(GBString::OnHitEffect))
		{
			if (!Effect->IsEmpty())
			{
				Info.OnHitEffect = FName(**Effect);
			}
		}
	}

	// The enchant's damage multiplier arrives by itself through its "Weapon.Gun.Damage" modifier.
	bool bElementFromEnchant = false;
	EGBElement EnchantElement = EGBElement::Physical;
	FName EnchantEffect = NAME_None;
	if (AcceptsEnchant() && GetActiveEnchant(EnchantElement, EnchantEffect))
	{
		Info.Element = EnchantElement;
		if (!EnchantEffect.IsNone())
		{
			Info.OnHitEffect = EnchantEffect;
		}
		bElementFromEnchant = true;
	}

	const int32 ElementIndex = GBElemental::ElementIndex(Info.Element);
	if (ElementIndex >= 0)
	{
		Info.BuildUp = GetStat(GBElemental::WeaponBuildUpKey(ElementIndex), 0.f);
		if (bElementFromEnchant)
		{
			Info.BuildUp *= GetStat(GBStat::EnchantBuildUpMult, 1.f);
		}
		const UGBDataSubsystem* Data = UGBDataSubsystem::Get(this);
		const float DefaultMult = Data ? Data->GetGameValue(GBStat::WeakPointBuildUpMult, 1.f) : 1.f;
		Info.WeakPointBuildUpMult = GetStat(GBStat::WeakPointBuildUpMult, DefaultMult);
	}
	Info.BuildUpEventId = UGBCombatLibrary::NewBuildUpEventId();
	return Info;
}

bool AGBHeldItem::IsAttackReady() const
{
	return GetTimeSinceLastAttack() >= GetStat(GBStat::FireInterval, 0.f);
}

void AGBHeldItem::UpdateTrigger()
{
	if (!bEquipped || !(bAttackQueued || (bTriggerHeld && IsAutomatic())))
	{
		return;
	}
	if (!IsAttackReady())
	{
		return; // a pressed shot stays queued until the fire interval has passed
	}

	const AGBPlayerCharacter* Player = GetPlayerOwner();
	const UGBSpellbookComponent* Spellbook = Player ? Player->GetSpellbook() : nullptr;
	if (!Player || Player->IsDead() || (Spellbook && Spellbook->IsBusy()))
	{
		bAttackQueued = false;
		return;
	}

	if (PerformAttack())
	{
		if (const UWorld* World = GetWorld())
		{
			LastAttackTime = World->GetTimeSeconds();
		}
	}
	bAttackQueued = false;
}

void AGBHeldItem::Tick(float DeltaSeconds)
{
	Super::Tick(DeltaSeconds);
	UpdateTrigger();
}

FVector AGBHeldItem::FindAimPoint(float Range) const
{
	const AGBPlayerCharacter* Player = GetPlayerOwner();
	if (!Player)
	{
		return GetActorLocation();
	}
	const FVector Start = Player->GetAimOrigin();
	const FVector End = Start + Player->GetAimDirection() * Range;

	FCollisionQueryParams Params(SCENE_QUERY_STAT(GBAimPoint), false, Player);
	Params.AddIgnoredActor(this);
	FHitResult Hit;
	if (GetWorld() && GetWorld()->LineTraceSingleByChannel(Hit, Start, End, GBWeapon::AimTraceChannel, Params))
	{
		return Hit.ImpactPoint;
	}
	return End;
}

	const AGBPlayerCharacter* Player = GetPlayerOwner();
	if (UGBEquipmentComponent* Equipment = Player ? Player->GetEquipment() : nullptr)
	{
		Equipment->OnEquipmentChanged.Broadcast();
	}
}

// ---- Modifiers: (base + adds) x product of multipliers; a perk's Multiply stacks in a straight line with its rank ----
function applyMods(base, keys, ranks) {
	let add = 0;
	let mult = 1;
	for (const id of Object.keys(ranks || {})) {
		const node = skillById[id];
		if (!node) { throw new Error('unknown skill ' + id); }
		const rank = Math.min(ranks[id], node.MaxRank);
		for (const m of node.ModifiersPerRank) {
			if (keys.indexOf(m.Stat) < 0) { continue; }
			if (m.Op === 'Add') { add += m.Value * rank; }
			else if (m.Op === 'Multiply') { mult *= 1 + (m.Value - 1) * rank; }
		}
	}
	return (base + add) * mult;
}
function buildCost(ranks) {
	return Object.keys(ranks).reduce((a, id) => a + skillById[id].Cost * ranks[id], 0);
}
const qteParam = (p) => p.ScaledBy === 'None' ? p.Base : p.Min + (p.Max - p.Min) * ASSUME.QteScore;

// ---- Weapon enchant at a typical QTE ----
const enchantSpell = spellById[player.EnchantSpell];
const enchantEffect = effects.find((f) => f.Id.indexOf('Enchant_') === 0);
const enchantBonus = enchantEffect ? enchantEffect.Modifiers[0].Value - 1 : 0;
function enchant(ranks) {
	if (!enchantSpell) { return { mult: 1, uptime: 0 }; }
	const p = enchantSpell.Params;
	const cooldown = applyMods(p.Cooldown.Base, ['Spell.All.Cooldown', 'Spell.WeaponEnchant.Cooldown'], ranks);
	const uptime = Math.min(1, qteParam(p.Duration) / cooldown);
	return { mult: 1 + enchantBonus * qteParam(p.EffectStrength), uptime, cooldown };
}

// ---- Weapons ----
function weaponRow(w, ranks, useEnchant) {
	const stat = (name) => applyMods(w.Stats[name] === undefined ? (name.indexOf('Mult') >= 0 ? 1 : 0) : w.Stats[name],
		['Weapon.All.' + name, 'Weapon.' + w.Slot + '.' + name, 'Weapon.' + w.Id + '.' + name], ranks);
	const pellets = w.Stats.Pellets || 1;
	const near = w.Stats.FalloffNearMult === undefined ? 1 : stat('FalloffNearMult');
	const far = w.Stats.FalloffFarMult === undefined ? 1 : stat('FalloffFarMult');
	const best = Math.max(near, far);
	const hit = stat('Damage') * pellets * best;
	const interval = stat('FireInterval');
	const burst = hit / interval;
	let sustained = burst;
	let rounds = Infinity;
	const mag = w.Stats.MagazineSize || 0;
	if (mag) {
		sustained = hit * mag / (mag * interval + stat('ReloadTime'));
		rounds = mag * (1 + (w.Stats.SpareMagazines || 0));
	}
	const head = stat('HeadshotMult') || 1;
	const accuracy = ASSUME.WeaponAccuracy[w.Id] || ASSUME.Accuracy;
	const headFactor = 1 + ASSUME.HeadShare * (head - 1);
	const en = useEnchant && w.Slot === 'Gun' ? enchant(ranks) : { mult: 1, uptime: 0 };
	const enchantFactor = 1 + en.uptime * (en.mult - 1);
	const perShot = hit * accuracy * headFactor * enchantFactor; // expected damage of one trigger pull
	const buildUp = Math.max(w.Stats.FireBuildUp || 0, w.Stats.LightningBuildUp || 0, w.Stats.IceBuildUp || 0);
	return {
		id: w.Id, slot: w.Slot, hit, burst, sustained, head, accuracy, mag, perShot,
		nearSustained: sustained * near / best, farSustained: sustained * far / best,
		expected: sustained * accuracy * ASSUME.Uptime * headFactor * enchantFactor,
		carried: rounds === Infinity ? Infinity : rounds * hit,          // paper damage carried
		carriedExpected: rounds === Infinity ? Infinity : rounds * perShot, // damage it really deals before running dry
		magExpected: mag * perShot,
		buildUpPerSecond: buildUp / interval
	};
}

// ---- Casting schedule: mana only comes back after ManaRegenDelay without spending ----
// A player who casts as often as the mana allows: one cast of cost C every C / regen + delay game seconds.
function casting(ranks, fightSeconds, targets) {
	const direct = ['Fireball', 'LightningBolt', 'LightningRune'].map((id) => spellById[id]).filter(Boolean);
	let cost = 0;
	let damage = 0;
	for (const sp of direct) {
		cost += applyMods(sp.Params.ManaCost.Base, ['Spell.All.ManaCost', 'Spell.' + sp.Id + '.ManaCost'], ranks);
		damage += applyMods(qteParam(sp.Params.Damage), ['Spell.All.Damage', 'Spell.' + sp.Id + '.Damage'], ranks);
	}
	cost /= direct.length;
	damage /= direct.length;
	const period = cost / ps.ManaRegen + ps.ManaRegenDelay;     // game seconds between casts once the bar is empty
	const castsPerSecond = 1 / period + (ps.MaxMana / cost) / Math.max(fightSeconds, 1); // plus the starting bar
	return { cost, damage, period, castsPerSecond, dps: damage * castsPerSecond * (targets || 1) };
}

// ---- Fight simulation ----
// The gun fires until its ammo (carried + what the enemies drop) is gone, then the free weapon takes over. Spells run all the time.
function simulate(health, build, opts) {
	const cast = casting(build.ranks, opts.guessSeconds || 90, opts.targets || 1);
	const gunDps = build.gun.expected;
	const freeDps = build.free.expected;
	const ammo = build.gun.carriedExpected + (opts.dropMagazines || 0) * build.gun.magExpected;
	const gunSeconds = ammo / gunDps;
	let seconds;
	let ammoShare;
	if ((gunDps + cast.dps) * gunSeconds >= health) {
		seconds = health / (gunDps + cast.dps);
		ammoShare = (gunDps * seconds) / ammo;
	} else {
		seconds = gunSeconds + (health - (gunDps + cast.dps) * gunSeconds) / (freeDps + cast.dps);
		ammoShare = 1;
	}
	const real = seconds * (1 + qteExtra * cast.castsPerSecond) + (opts.subWaves || 0) * ASSUME.WaveOverhead;
	return { game: seconds + (opts.subWaves || 0) * ASSUME.WaveOverhead, real, ammoShare };
}

FGBAmmoState UGBEquipmentComponent::ComputeFullAmmo(FName WeaponId) const
{
	FGBAmmoState Full;
	const UGBDataSubsystem* Data = UGBDataSubsystem::Get(this);
	const FGBWeaponDefinition* Def = Data ? Data->FindWeapon(WeaponId) : nullptr;
	if (!Def || Def->Slot != EGBHeldSlot::Gun)
	{
		return Full;
	}
	const UGBStatsComponent* Stats = UGBStatsComponent::Find(GetOwner());
	// Same keys and defaults as AGBHeldItem::GetStat / AGBGun, so a stored gun refills to what it would hold in hand.
	auto ReadStat = [Def, Stats, WeaponId](FName Stat, float DefaultValue)
	{
		const float* Found = Def->Stats.Find(Stat);
		const float Base = Found ? *Found : DefaultValue;
		if (!Stats)
		{
			return Base;
		}
		TArray<FName, TInlineAllocator<3>> Keys;
		Keys.Add(GBStat::WeaponKey(WeaponId, Stat));
		Keys.Add(GBStat::WeaponSlotKey(EGBHeldSlot::Gun, Stat));
		Keys.Add(GBStat::WeaponAllKey(Stat));
		return Stats->EvaluateKeys(Keys, Base);
	};
	Full.InMagazine = FMath::Max(0, FMath::RoundToInt(ReadStat(GBStat::MagazineSize, 1.f)));
	Full.SpareMagazines = FMath::Max(0, FMath::RoundToInt(ReadStat(GBStat::SpareMagazines, 0.f)));
	if (ReadStat(GBStat::ReloadPerRound, 0.f) > 0.5f)
	{
		// A round-by-round gun counts its reserve in rounds: the same total as the magazines would have held.
		Full.SpareMagazines *= Full.InMagazine;
	}
	return Full;
}

bool UGBEquipmentComponent::GetWeaponAmmo(FName WeaponId, FGBAmmoState& OutAmmo) const

AGBHeldItem* UGBEquipmentComponent::SpawnItem(FName WeaponId)
{
	AGBPlayerCharacter* Player = Cast<AGBPlayerCharacter>(GetOwner());
	UWorld* World = GetWorld();
	const UGBDataSubsystem* Data = UGBDataSubsystem::Get(this);
	const FGBWeaponDefinition* Def = Data ? Data->FindWeapon(WeaponId) : nullptr;
	if (!Player || !World || !Def)
	{
		UE_LOG(LogGB, Warning, TEXT("GiveWeapon: unknown weapon '%s' (or no player / world)"), *WeaponId.ToString());
		return nullptr;
	}

	UClass* ItemClass = nullptr;
	if (!Def->ActorClass.IsEmpty())
	{
		ItemClass = LoadClass<AGBHeldItem>(nullptr, *Def->ActorClass);
		if (!ItemClass || ItemClass->HasAnyClassFlags(CLASS_Abstract))
		{
			UE_LOG(LogGB, Warning, TEXT("Weapon '%s': ActorClass '%s' not found or abstract, using the slot default"), *WeaponId.ToString(), *Def->ActorClass);
			ItemClass = nullptr;
		}
	}
	if (!ItemClass)
	{
		switch (Def->Slot)
		{
		case EGBHeldSlot::Staff: ItemClass = AGBStaff::StaticClass(); break;
		case EGBHeldSlot::Sword: ItemClass = AGBSword::StaticClass(); break;
		default: ItemClass = AGBGun::StaticClass(); break;
		}
	}

	// Copy the definition: spawning must not rely on a pointer into the data tables.
	const FGBWeaponDefinition Definition = *Def;

	FActorSpawnParameters Params;
	Params.Owner = Player;
	Params.Instigator = Player;
	Params.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AlwaysSpawn;
	AGBHeldItem* Item = World->SpawnActor<AGBHeldItem>(ItemClass, Player->GetActorTransform(), Params);
	if (!Item)
	{
		UE_LOG(LogGB, Warning, TEXT("GiveWeapon: could not spawn '%s'"), *WeaponId.ToString());
		return nullptr;
	}

	USceneComponent* Anchor = Player->GetHeldItemAnchor() ? Player->GetHeldItemAnchor() : Player->GetRootComponent();
	Item->AttachToComponent(Anchor, FAttachmentTransformRules::SnapToTargetNotIncludingScale);
	Item->InitFromDefinition(Definition, Player);
	Item->OnUnequipped();
	Item->RefillAmmo();
	return Item;
}

void UGBEquipmentComponent::StoreItemState(AGBHeldItem* Item)
{
	if (!IsValid(Item))
	{
		return;
	}
	Item->StopPrimary();
	Item->StopSecondary();
	Item->OnUnequipped(); // a gun cancels its reload here

	const FName WeaponId = Item->GetWeaponId();
	StoredElements.Add(WeaponId, Item->GetElement());
	if (Item->UsesAmmo())
	{
		StoredAmmo.Add(WeaponId, Item->GetAmmo());
	}
}

void UGBEquipmentComponent::RestoreItemState(AGBHeldItem* Item)
{
	if (!IsValid(Item))
	{
		return;
	}
	const FName WeaponId = Item->GetWeaponId();
	if (const EGBElement* Element = StoredElements.Find(WeaponId))
	{
		Item->SetElement(*Element);
	}
	if (const FGBAmmoState* Ammo = StoredAmmo.Find(WeaponId))
	{
		Item->SetAmmo(*Ammo); // a gun never held has no entry and stays full from SpawnItem
	}
	// While in a slot, the actor is the only source of truth.
	StoredElements.Remove(WeaponId);
	StoredAmmo.Remove(WeaponId);
}

AGBHeldItem* UGBEquipmentComponent::GiveWeapon(FName WeaponId, bool bAutoSwitch, bool /*bDropOld*/)
{
	EGBHeldSlot NewSlot = EGBHeldSlot::Staff;
	if (!FindWeaponSlot(WeaponId, NewSlot))
	{
		UE_LOG(LogGB, Warning, TEXT("GiveWeapon: unknown weapon '%s'"), *WeaponId.ToString());
		return nullptr;
	}

	if (OwnsWeapon(WeaponId))
	{
		return FindEquippedItem(WeaponId);
	}

	// Owner's rule (2026-11-12): nothing is dropped and the weapon in hand is never replaced.
	if (HasWeaponInSlot(NewSlot))
	{
		OwnedWeapons.Add(WeaponId);
		if (NewSlot == EGBHeldSlot::Gun)
		{
			StoredAmmo.Add(WeaponId, ComputeFullAmmo(WeaponId));
		}
		OnEquipmentChanged.Broadcast();
		return nullptr;
	}

	const bool bHandsEmpty = GetActiveItem() == nullptr;
	AGBHeldItem* NewItem = SpawnItem(WeaponId);
	if (!NewItem)
	{
		return nullptr;
	}
	OwnedWeapons.Add(WeaponId);
	Items.Add(NewSlot, NewItem);

	if (bHandsEmpty)
	{
		EquipSlot(NewSlot);
	}
	else if (!bAutoSwitch || !SwitchTo(NewSlot))
	{
		OnEquipmentChanged.Broadcast();
	}
	return NewItem;
}

bool UGBEquipmentComponent::EquipOwnedWeapon(FName WeaponId)
{
	if (bSwitchLocked || !OwnsWeapon(WeaponId) || IsWeaponEquipped(WeaponId))
	{
		return false;
	}
	EGBHeldSlot Slot = EGBHeldSlot::Staff;
	if (!FindWeaponSlot(WeaponId, Slot))
	{
		UE_LOG(LogGB, Warning, TEXT("EquipOwnedWeapon: '%s' is no longer in Weapons.json"), *WeaponId.ToString());
		return false;
	}

	AGBHeldItem* Old = GetItemInSlot(Slot);
	// The new item comes up if it replaces the one in the hands (or the hands are empty).
	const bool bBringUp = ActiveSlot == Slot || GetActiveItem() == nullptr;

	AGBHeldItem* NewItem = SpawnItem(WeaponId);
	if (!NewItem)
	{
		return false;
	}
	if (Old)
	{
		StoreItemState(Old);
		Old->Destroy();
	}
	Items.Add(Slot, NewItem);
	RestoreItemState(NewItem);

	if (bBringUp)
	{
		EquipSlot(Slot); // cancels a sustained spell, broadcasts both delegates
		return true;
	}

	if (const AGBPlayerCharacter* Player = Cast<AGBPlayerCharacter>(GetOwner()))
	{
		if (UGBSpellbookComponent* Spellbook = Player->GetSpellbook())
		{
			Spellbook->CancelSustained();
		}
	}
	OnEquipmentChanged.Broadcast();
	return true;
}

void UGBEquipmentComponent::EquipSlot(EGBHeldSlot Slot)
{
	AGBHeldItem* Target = GetItemInSlot(Slot);
	AGBHeldItem* Current = GetItemInSlot(ActiveSlot);
	if (Current && Current != Target && Current->IsEquipped())
	{
		Current->StopPrimary();
		Current->StopSecondary();
		Current->OnUnequipped();
	}

	ActiveSlot = Slot;

	if (const AGBPlayerCharacter* Player = Cast<AGBPlayerCharacter>(GetOwner()))
	{
		if (UGBSpellbookComponent* Spellbook = Player->GetSpellbook())
		{
			Spellbook->CancelSustained();
		}
	}

	if (Target && !Target->IsEquipped())
	{
		Target->OnEquipped();
	}

	OnActiveItemChanged.Broadcast(Target);
	OnEquipmentChanged.Broadcast();
}

bool UGBEquipmentComponent::SwitchTo(EGBHeldSlot Slot)
{
	if (bSwitchLocked || !HasWeaponInSlot(Slot))
	{
		return false;
	}
	if (Slot == ActiveSlot && GetActiveItem() != nullptr)
	{
		return true;
	}
	EquipSlot(Slot);
	return true;
}

void UGBEquipmentComponent::CycleSlot(int32 Direction)
{
	if (bSwitchLocked)
	{
		return;
	}
	const int32 Count = static_cast<int32>(UE_ARRAY_COUNT(EquipSlotOrder));
	const int32 Step = Direction >= 0 ? 1 : -1;
	const int32 Start = EquipSlotIndex(ActiveSlot);
	for (int32 Offset = 1; Offset < Count; ++Offset)
	{
		const int32 Index = ((Start + Step * Offset) % Count + Count) % Count;
		if (HasWeaponInSlot(EquipSlotOrder[Index]))
		{
			SwitchTo(EquipSlotOrder[Index]);
			return;
		}
	}
}

TMap<EGBHeldSlot, FName> UGBEquipmentComponent::ChooseEquippedWeapons(const TArray<FName>& Owned, const TArray<FName>& Equipped,
	TFunctionRef<bool(FName, EGBHeldSlot&)> SlotOf)
{
	TMap<EGBHeldSlot, FName> Result;
	auto TryPlace = [&Result, &SlotOf](FName WeaponId)
	{
		EGBHeldSlot Slot = EGBHeldSlot::Staff;
		if (!WeaponId.IsNone() && SlotOf(WeaponId, Slot) && !Result.Contains(Slot))
		{
			Result.Add(Slot, WeaponId);
		}
	};
	for (const FName& WeaponId : Equipped)
	{
		if (Owned.Contains(WeaponId))
		{
			TryPlace(WeaponId);
		}
	}
	for (const FName& WeaponId : Owned)
	{
		TryPlace(WeaponId);
	}
	return Result;
}

void UGBEquipmentComponent::SaveToSnapshot(FGBPlayerSnapshot& Snapshot) const
{
	Snapshot.Weapons = OwnedWeapons;
	Snapshot.EquippedWeapons.Reset();
	Snapshot.Ammo.Reset();
	Snapshot.WeaponElements.Reset();

	for (const TPair<EGBHeldSlot, TObjectPtr<AGBHeldItem>>& Pair : Items)
	{
		const AGBHeldItem* Item = Pair.Value.Get();
		if (!IsValid(Item))
		{
			continue;
		}
		const FName WeaponId = Item->GetWeaponId();
		Snapshot.Weapons.AddUnique(WeaponId);
		Snapshot.EquippedWeapons.Add(WeaponId);
		Snapshot.WeaponElements.Add(WeaponId, Item->GetElement());
		if (Item->UsesAmmo())
		{
			Snapshot.Ammo.Add(WeaponId, Item->GetAmmo());
		}
	}
	for (const TPair<FName, FGBAmmoState>& Pair : StoredAmmo)
	{
		if (!Snapshot.Ammo.Contains(Pair.Key))
		{
			Snapshot.Ammo.Add(Pair.Key, Pair.Value);
		}
	}
	for (const TPair<FName, EGBElement>& Pair : StoredElements)
	{
		if (!Snapshot.WeaponElements.Contains(Pair.Key))
		{
			Snapshot.WeaponElements.Add(Pair.Key, Pair.Value);
		}
	}
	Snapshot.ActiveSlot = ActiveSlot;
}

void UGBEquipmentComponent::LoadFromSnapshot(const FGBPlayerSnapshot& Snapshot)
{
	DestroyAllItems();
	OwnedWeapons.Reset();
	StoredAmmo.Reset();
	StoredElements.Reset();

	for (const FName& WeaponId : Snapshot.Weapons)
	{
		EGBHeldSlot Slot = EGBHeldSlot::Staff;
		if (FindWeaponSlot(WeaponId, Slot))
		{
			OwnedWeapons.AddUnique(WeaponId);
		}
		else
		{
			UE_LOG(LogGB, Warning, TEXT("Equipment snapshot: weapon '%s' is not in Weapons.json; dropped."), *WeaponId.ToString());
		}
	}

	const TMap<EGBHeldSlot, FName> ToEquip = ChooseEquippedWeapons(OwnedWeapons, Snapshot.EquippedWeapons,
		[this](FName WeaponId, EGBHeldSlot& OutSlot) { return FindWeaponSlot(WeaponId, OutSlot); });

	for (const FName& WeaponId : OwnedWeapons)
	{
		EGBHeldSlot Slot = EGBHeldSlot::Staff;
		FindWeaponSlot(WeaponId, Slot);
		const bool bEquipped = ToEquip.FindRef(Slot) == WeaponId;

		if (bEquipped)
		{
			if (AGBHeldItem* Item = SpawnItem(WeaponId))
			{
				Items.Add(Slot, Item);
				if (const EGBElement* SavedElement = Snapshot.WeaponElements.Find(WeaponId))
				{
					Item->SetElement(*SavedElement);
				}
				if (const FGBAmmoState* SavedAmmo = Snapshot.Ammo.Find(WeaponId))
				{
					Item->SetAmmo(*SavedAmmo);
				}
			}
			continue;
		}

		if (const EGBElement* SavedElement = Snapshot.WeaponElements.Find(WeaponId))
		{
			StoredElements.Add(WeaponId, *SavedElement);
		}
		if (Slot == EGBHeldSlot::Gun)
		{
			const FGBAmmoState* SavedAmmo = Snapshot.Ammo.Find(WeaponId);
			StoredAmmo.Add(WeaponId, SavedAmmo ? *SavedAmmo : ComputeFullAmmo(WeaponId));
		}
	}

	EGBHeldSlot Slot = Snapshot.ActiveSlot;
	if (!HasWeaponInSlot(Slot))
	{
		for (const EGBHeldSlot Candidate : EquipSlotOrder)
		{
			if (HasWeaponInSlot(Candidate))
			{
				Slot = Candidate;
				break;
			}
		}
	}

	if (HasWeaponInSlot(Slot))
	{
		EquipSlot(Slot);
	}
	else
	{
		ActiveSlot = Snapshot.ActiveSlot;
		OnActiveItemChanged.Broadcast(nullptr);
		OnEquipmentChanged.Broadcast();
	}
}

void UGBStatsComponent::AddModifiers(FName Source, TConstArrayView<FGBModifierDef> Modifiers, float ValueScale)
{
	ActiveModifiers.RemoveAll([Source](const FSourcedModifier& Entry) { return Entry.Source == Source; });

	for (const FGBModifierDef& Modifier : Modifiers)
	{
		FSourcedModifier& Entry = ActiveModifiers.AddDefaulted_GetRef();
		Entry.Source = Source;
		Entry.Modifier = Modifier;
		switch (Modifier.Op)
		{
		case EGBModOp::Add:
			Entry.Modifier.Value = Modifier.Value * ValueScale;
			break;
		case EGBModOp::Multiply:
			// Scaled around 1, so a x1.5 buff at half strength is x1.25, not x0.75.
			Entry.Modifier.Value = 1.f + (Modifier.Value - 1.f) * ValueScale;
			break;
		case EGBModOp::MultiplyMin:
			// Same scaling as Multiply: the strongest slow at partial strength stays a slow.
			Entry.Modifier.Value = 1.f + (Modifier.Value - 1.f) * ValueScale;
			break;
		case EGBModOp::Override:
			break;
		}
	}

	OnStatsChanged.Broadcast();
}

void UGBStatsComponent::RemoveModifiers(FName Source)
{
	if (ActiveModifiers.RemoveAll([Source](const FSourcedModifier& Entry) { return Entry.Source == Source; }) > 0)
	{
		OnStatsChanged.Broadcast();
	}
}

bool UGBStatsComponent::HasModifierSource(FName Source) const
{
	return ActiveModifiers.ContainsByPredicate([Source](const FSourcedModifier& Entry) { return Entry.Source == Source; });
}

float UGBStatsComponent::ApplyModifiers(float Base, TConstArrayView<FGBModifierDef> Modifiers)
{
	float Sum = Base;
	float Product = 1.f;
	float LowestMin = 1.f;
	bool bHasMin = false;
	const FGBModifierDef* LastOverride = nullptr;

	for (const FGBModifierDef& Modifier : Modifiers)
	{
		switch (Modifier.Op)
		{
		case EGBModOp::Add:
			Sum += Modifier.Value;
			break;
		case EGBModOp::Multiply:
			Product *= Modifier.Value;
			break;
		case EGBModOp::MultiplyMin:
			if (!bHasMin || Modifier.Value < LowestMin)
			{
				LowestMin = Modifier.Value;
				bHasMin = true;
			}
			break;
		case EGBModOp::Override:
			LastOverride = &Modifier;
			break;
		}
	}

	return LastOverride ? LastOverride->Value : Sum * Product * (bHasMin ? LowestMin : 1.f);
}

EGBSkillUnlockResult UGBSkillTreeComponent::Unlock(FName NodeId)
{
	const UGBDataSubsystem* Data = UGBDataSubsystem::Get(this);
	const FGBSkillNodeDefinition* Node = Data ? Data->FindSkillNode(NodeId) : nullptr;
	if (!Node)
	{
		UE_LOG(LogGB, Warning, TEXT("Unlock: unknown skill node '%s'."), *NodeId.ToString());
		return EGBSkillUnlockResult::UnknownNode;
	}

	const EGBSkillUnlockResult Result = EvaluateUnlock(*Node, Ranks, Points);
	if (Result != EGBSkillUnlockResult::Ok)
	{
		return Result;
	}

	Points -= FMath::Max(0, Node->Cost);
	PointsSpent += FMath::Max(0, Node->Cost);
	Ranks.FindOrAdd(NodeId) += 1;
	ApplyNodeModifiers(NodeId);
	OnSkillsChanged.Broadcast();
	return EGBSkillUnlockResult::Ok;
}

int32 UGBSkillTreeComponent::ResetAll()
{
	if (Ranks.Num() == 0)
	{
		return 0;
	}
	RemoveAllModifiers();
	const int32 Refunded = PointsSpent;
	Points += PointsSpent;
	PointsSpent = 0;
	Ranks.Reset();
	OnSkillsChanged.Broadcast();
	return Refunded;
}

EGBSkillUnlockResult UGBSkillTreeComponent::EvaluateUnlock(const FGBSkillNodeDefinition& Node, const TMap<FName, int32>& InRanks, int32 AvailablePoints)
{
	if (InRanks.FindRef(Node.Id) >= Node.MaxRank)
	{
		return EGBSkillUnlockResult::MaxRank;
	}
	for (const FName& Required : Node.Requires)
	{
		if (!Required.IsNone() && InRanks.FindRef(Required) <= 0)
		{
			return EGBSkillUnlockResult::MissingRequirement;
		}
	}
	if (AvailablePoints < Node.Cost)
	{
		return EGBSkillUnlockResult::NotEnoughPoints;
	}
	return EGBSkillUnlockResult::Ok;
}

void UGBSkillTreeComponent::ApplyNodeModifiers(FName NodeId)
{
	UGBStatsComponent* Stats = UGBStatsComponent::Find(GetOwner());
	if (!Stats)
	{
		return;
	}

	const FName Source = ModifierSource(NodeId);
	const int32 Rank = GetRank(NodeId);
	const UGBDataSubsystem* Data = UGBDataSubsystem::Get(this);
	const FGBSkillNodeDefinition* Node = Data ? Data->FindSkillNode(NodeId) : nullptr;
	if (!Node || Rank <= 0)
	{
		if (!Node && Rank > 0)
		{
			UE_LOG(LogGB, Warning, TEXT("Skill node '%s' is owned but missing from Skills.json; its modifiers are off."), *NodeId.ToString());
		}
		Stats->RemoveModifiers(Source);
		return;
	}

	// ValueScale = rank: Add modifiers count once per rank, Multiply modifiers stack linearly (not compounding).
	Stats->AddModifiers(Source, Node->ModifiersPerRank, static_cast<float>(Rank));
}

void UGBSkillTreeComponent::RemoveAllModifiers()
{
	UGBStatsComponent* Stats = UGBStatsComponent::Find(GetOwner());
	if (!Stats)
	{
		return;
	}
	for (const TPair<FName, int32>& Pair : Ranks)
	{
		Stats->RemoveModifiers(ModifierSource(Pair.Key));
	}
}

void UGBSkillTreeComponent::ReapplyAllModifiers()
{
	for (const TPair<FName, int32>& Pair : Ranks)
	{
		ApplyNodeModifiers(Pair.Key);
	}
}

		return;
	}

	if (bValue)
	{
		Flags.Add(Flag);
	}
	else
	{
		Flags.Remove(Flag);
	}
	UE_LOG(LogGB, Log, TEXT("Progress: flag %s = %s"), *Flag.ToString(), bValue ? TEXT("true") : TEXT("false"));

}

void UGBProgressSubsystem::SaveCheckpoint(AGBPlayerCharacter* Player)
{
	if (!Player)
	{
		UE_LOG(LogGB, Warning, TEXT("Progress: SaveCheckpoint without a player."));
		return;
	}

	FGBPlayerSnapshot Snapshot;
	Player->SaveToSnapshot(Snapshot);
	Snapshot.bValid = true;
	Checkpoint = MoveTemp(Snapshot);
	OnCheckpointSaved.Broadcast();
}

bool UGBProgressSubsystem::RestoreCheckpoint(AGBPlayerCharacter* Player)
{
	if (!Player || !Checkpoint.bValid)
	{
		return false;
	}
	Player->RespawnAt(Checkpoint);
	return true;
}

void UGBProgressSubsystem::ResetProgress()
{
	const TSet<FName> Cleared = MoveTemp(Flags);
	Flags.Reset();
	Checkpoint = FGBPlayerSnapshot();
	for (const FName& Flag : Cleared)
	{
		OnFlagChanged.Broadcast(Flag);
	}
}
